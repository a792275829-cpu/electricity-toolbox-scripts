# 广东运行日报解析上传

该模块用于解析《广东电力现货市场运行日报》第 3 页“报价分布”柱状图，生成燃煤、燃气、新能源分报价区间容量 Excel，并按 PDF 报告日期上传至清能网站数据中心。

它兼容报告中的内嵌图和页面渲染图，并从“日前申报信息”表读取“零价及以下”及“报价 600 以上”的分类汇总值，对图像识别结果进行校准。

也支持中文表头和行标签为图片、容量数值为文本的日报格式（如 2026-10-15）。常规文本提取失败时，自动使用 macOS 自带 Vision 识别中文标签，按表格单元格位置恢复字段映射；容量始终读取 PDF 原始文本，不使用 OCR 数值，也不依赖固定行号。识别在本机完成，无需额外安装 OCR 软件。日志会显示是否使用了图片标签识别。

针对矮柱和薄堆叠段，解析器从柱形内部学习实际配色，按颜色覆盖率累计小数像素高度，拆分堆叠边界的混合颜色，并对 JPEG 饱和度损失进行补偿。网格线按同行背景扣除；只有两侧均有柱形证据的短网格遮挡才补齐，不给所有矮柱统一加固定高度。汇总校准完成后才保留一位小数，避免细小分段提前舍入为零。

横轴定位会排除脱离标签主体的细括号笔画，按完整标签的等间距确定报价档位；标签不可读时，后备逻辑按实测柱间距与绘图区宽度确定档位数，不再按固定 48 档估算，避免容量被错放到相邻价格区间。

每根柱形还会单独验证电源颜色证据：分类需有相符色相，或明确的混色边界。缺少证据的分类会移出该柱形的颜色模型，再重新估算容量，防止偏紫的红色燃气柱被分解出蓝色燃煤、并被汇总校准放大。此检查适用于所有报价区间。

日志会提示不足 3 个原图像素的电源分段，以及校准前每像素对应的 MW。小数像素估算能降低量化误差，但不能恢复完全被遮挡、压缩丢失的信息，也不代表达到 0.1 MW 的真实精度。“报价 600 以上”某类电源全部未识别、而表格汇总大于零时，会明确报错，避免把汇总值放入最后一档。

## 独立运行

```bash
../.venv/bin/python run_daily_pdf_parser.py "/path/to/运行日报.pdf"
```

默认执行“解析并上传”：回读 Excel 后，将源 PDF 上传到“现货交易日报”，将 Excel 上传到“报价容量数据”。每个页签均将数据日期设为报告当天，选择该日期行的文件，再执行“全部上传”。完成后核对网站日期、上传状态和完成时间，PDF 同时核对网站文件名。报价容量导入服务保存解析后的数据，状态接口不保留 Excel 文件名，因此 Excel 名称在提交前由网页确认，并结合导入接口结果核验。

可通过 `-o` 指定输出 Excel；仅在 PDF 无法自动识别申报容量时才需要 `--baseline`。支持 `--mode parse` 仅解析，或 `--mode upload -o "/path/to/已有解析.xlsx"` 上传源 PDF 和已有 Excel。上传失败会保留本地文件，并报告已成功的步骤；可用“仅上传”重试。网站已有同日记录时，重新上传会更新该日期的数据。

账号复用工具箱任务中心的清能网站账号配置，模块独立使用本目录内的 `auth_state.json`、`auth_state.json.lock` 和 `.browser-profile/`，均由 Git 忽略。自动切换到有数据中心权限的广东分公司；日期不明、文件日期冲突、Excel 校验失败或日期行不能唯一匹配时停止上传。

macOS 日常使用请直接从“电力工具箱”侧栏的“数据采集”分类打开“广东运行日报解析上传”。
