# 广东电价预测

工具箱“数据采集 → 广东电价预测”。两件事：补齐广东现货历史数据总表，然后用滚动训练生成 D+1 至 D+15 日前电价预测。

## 使用

补齐数据总表：

1. 确认工具箱右侧“清能网站账号”已配置。
2. 填写“运行日 D”。
3. 点击“补齐数据总表”。总表固定保留截至 D 的近一个自然年：起日为 D 往前一年后的次日，末日为 D，两端均包含。例如 D 为 `2026-11-04` 时，范围为 `2025-11-05`～`2026-11-04`，闰年窗口可能有 366 天。
4. 工具只在上述范围内检查标准 96 时点、日前电价和已发布的供需字段，补抓缺口，并按 `refreshDays` 回看近期日期；首次创建也按完整窗口补抓。接口每批最多请求 31 天，共用本模块的一次登录，全部抓取成功后合并保存。
5. 早于起日或晚于 D 的记录截断，即使没有缺口也保存截断结果。增量空值不覆盖范围内已有有效值，字段顺序与数字格式保留，数据写入唯一的 `广东电价数据总表.xlsx`。

保存时先写临时文件，回读表头、首末行的值及数字格式，通过后才替换总表；失败保留原总表。默认格式的空单元格可在 XLSX 中省略，回读时按 `General` 校验；自定义数字格式仍须一致。

运行预测：

1. 确认总表路径；文件不存在时，界面预测流程会先按账号配置创建并补齐总表，历史数据满足要求后再训练。
2. 确认建模输入表与预测输出目录。
3. 设置“滚动训练月数”：默认 `0` 表示自动——预测日供需数据齐全时用 12 个月，需要回退时用 3 个月；手工指定时最少 1 个月，最大 24。
4. 设置“预测天数”：`1` 只输出 D+1，最多 `15` 输出 D+1 至 D+15，每天 96 点。
5. 点击“运行日前预测”，先按运行日 D 自动补齐当前总表，再训练并逐日递推；同时核验预测日供需曲线的发布时间。补齐失败时停止；补齐后仍无完整 D 日电价时保留时效校验，不用旧日期替代 D。

多日预测按天递推：D+1 用已发布的前一日供需，D+1 之后没有已发布供需曲线，供需类特征由模型按训练期填补，误差随天数放大。供需快照只核验 D+1，回退时整段改为历史供需滞后特征。

## 命令行

```bash
.venv/bin/python 广东电价预测/update_gdfire_data.py --date 2026-11-02
.venv/bin/python 广东电价预测/train_d1_forecast.py --update-master --training-months 0 --as-of 2026-11-02
.venv/bin/python 广东电价预测/train_d1_forecast.py --training-months 1 --forecast-days 15 --as-of 2026-11-02
```

`train_d1_forecast.py --forecast-days` 取 `1`～`15`，`--training-months` 取 `0`（自动）或 `1`～`24`；`--compare-algorithms`、`--historical-only`、`--fetch-future-inputs` 是开发期实验开关，日常不用。

界面预测命令自动携带 `--update-master`，按 `--as-of` 创建或更新所选总表，并保留近一年。独立命令不带该参数时直接读取已有输入，显式指定的输入不存在时停止，适用于历史归档；它与 `--compare-algorithms` 不可同时使用，避免截断实验输入。

## 配置

`广东电价预测/config.json`（从 `config.example.json` 复制，示例不含账号）：

| 字段 | 作用 |
| --- | --- |
| `masterWorkbook` | 长期维护的唯一数据总表，同时是默认建模输入 |
| `predictionOutputDir` | D+1 预测输出目录 |
| `initialWorkbook` | 首次创建总表时导入的历史表；已有总表时不再使用 |
| `refreshDays` | 已有总表默认回看最近 N 天补入延后发布或修订的数据；`0` 关闭回看，历史缺口仍补抓 |

相对路径以 `广东电价预测/` 为基准，支持 `~`。页面修改总表路径后，补齐与预测都使用该路径。日期范围固定按运行日计算，不使用本地配置中的 `initialDate`。

## 输出

- `广东电价预测/输出/广东电价数据总表.xlsx`
- `广东电价预测/输出/D+1预测/D+1日前电价.xlsx`：单日预测，D+1 日期 + 96 个十五分钟时点
- `广东电价预测/输出/D+1预测/D+1至D+15日前电价.xlsx`：多日预测，每天一个工作表（`D+1日前电价`…`D+15日前电价`），每个表 96 行
- `广东电价预测/输出/D+1预测/MAE.json`：模型误差指标，含 `forecast_days` 与 `target_dates`

建模自动排除实际、实时等会造成未来信息泄漏的字段。初始历史表放在 `广东电价预测/输入/广东数据初始总表.xlsx`，或用 `initialWorkbook` 指定。

安装包首次安装写入的是裁剪后的历史总表：近 12 个月、只含 `日期`、`时刻`、目标价与 10 个 `日前*` 出力列；打包不会修改仓库里的原始表。日常补齐将当前目标总表维持在截至 D 的近一年。滚动训练月数设为 24 时，也只能使用总表实际保留的历史。
