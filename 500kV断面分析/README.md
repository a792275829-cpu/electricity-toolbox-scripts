# 500kV断面分析

广东500kV节点电价清洗、断面识别与交互式拓扑网页生成模块。该项目已完整整理到电力工具箱仓库，日常使用优先从“电力工具箱 → 500kV断面分析”进入。

## 功能流程

1. 从内置拓扑的已确认连线端点生成500kV节点白名单。
2. 匹配数据源节点别名；同一拓扑节点存在多条记录时逐时取平均。
3. 检查相邻节点价格反向变化、两端价差严格超过阈值且全天累计至少4个时点的断面。
4. 清洗与断面明细在临时目录完成，最终只输出交互式HTML拓扑网页。
5. 网页颜色由累计触发时点和最大价差共同决定，越深表示异常越持久且价差越大。
6. 节点及断面电价曲线支持悬停或点按逐时查看时间和精确电价。拓扑右侧面板优先显示详情与曲线，断面导航、搜索、排序和列表位于曲线下方。
7. 拓扑图下方提供00:00—23:45共96格时间轴，每格15分钟，灰色滑轨不填充进度，当前HH:mm时间随圆点显示在下方；拖动、方向键或前后按钮切换时，全图线路直接显示该时点的方向箭头。方向沿用节点电价低价→高价的推断口径，同价或缺失数据时隐藏箭头；“潮流查看”可开关箭头，拖动时间轴自动恢复显示，悬停线路电价曲线时同步更新时间轴。原“断面强度”说明已移除。
8. 网页顶部“区域电价曲线”按“大区 → 市 → 节点”三级联动勾选，支持搜索、全选、清空、单节点对比、市／大区汇总、逐时读数和 CSV 导出；所有数据与脚本内嵌，离线可用。

曲线默认展示广州已具备电价的节点，可切换为按市或大区汇总。汇总仅使用已勾选节点，沿用原流程的同节点多母线逐时均价，再逐时对有效节点等权平均；弹框显示“有效节点数／已选节点数”，缺失值不当作零，全缺失时保留断点。时间滑杆支持键盘，图上悬停或点按读取时点，当前选择与汇总方式写入链接，刷新可恢复。窄窗口下选择器移到图表上方。

右上角“显示弹框”可在悬停／点按时查看半透明浮层，保留4位小数并显示当前时点；读数按图例顺序展示，最多12条。页面移除价格读数排序、来源与计算口径等说明小字。曲线按当前选择自动分配颜色，全部使用实线；点击图例色块可单独改色，点击名称显示／隐藏单条曲线，也可全部隐藏或恢复。隐藏只影响显示，不改变勾选节点、汇总分母或节点排名。CSV仅导出当前可见曲线，自定义颜色、排名方向、弹框开关和曲线可见性自动保存到当前地址，刷新可恢复。

图下方以两张紧凑排名卡片显示已勾选节点的日均价前10与倒数前10，前10标题旁的“切换倒序”可对调高低榜及排序方向。沿用每个节点的有效分时电价算术平均，展示有效时点数量；缺失不记零、全缺失不参与排名。未满96个有效时点时不表示完整日均价。两张卡片使用共同量尺：全正值从左端绘制，全负值从右端绘制，正负混合时按实际数值范围定位零点，充分使用条形宽度。

行政分类已保存为 `src/node_city_catalog.py` 中的功能配置，包含用户确认的徐闻开关站→湛江、玄陆升压站→汕尾、铜鼓电厂→江门、阳西A厂→阳江。阳西A厂虽然暂无接线边，仍纳入节点电价清洗及曲线菜单；不会据此增加连线或地图锚点。输入文件不含该节点电价时明确显示“暂无电价”，不合并为阳西厂、B厂或C厂。自定义拓扑新增的未知节点单列“未分类／待确认”。

默认价差阈值为 `80元/MWh`，可在工具箱页面或命令行调整。

## 目录结构

```text
500kV断面分析/
├── run_500kv_analysis.py        # 可重复运行的批处理入口
├── 500kV节点拓扑.md             # 节点白名单与断面拓扑
├── 接线图.png                   # 节点定位底图
├── src/                         # 清洗、分析、网页生成源码
├── data/                        # 已确认节点坐标和定位候选数据
├── tools/                       # 节点位置校准工具
├── tests/                       # 原项目完整单元测试
├── docs/                        # 设计与历史实施文档
└── local_data/                  # 原始数据及历史结果，仅保存在本机
```

`local_data/` 已加入仓库忽略规则，避免真实业务数据和生成报表进入版本控制。

## 工具箱运行

从仓库根目录双击 `电力工具箱.command`，选择侧栏的“500kV断面分析”：

1. 添加一份或多份节点电价 `.xlsx`。
2. 确认内置拓扑和输出目录。
3. 设置价差阈值，点击“开始分析”。
4. 完成后可直接打开结果目录或最近生成的网页。

也可以双击本目录的 `500kV 断面分析.command` 打开兼容的独立窗口。

## 命令行运行

在仓库根目录执行：

```bash
.venv/bin/python "500kV断面分析/run_500kv_analysis.py" \
  --output-root ~/Downloads \
  --threshold 80 \
  /path/to/日前节点电价查询.xlsx
```

可以一次传入多个Excel；每份输入最终只保留一个分析网页。

## 输出

每份输入数据会直接在输出目录生成一个网页，不创建结果子目录：

- `原数据文件名_500kV分析.html`

清洗Excel和断面明细Excel只作为临时计算文件，生成网页后自动删除；原始工作簿不会被覆盖。

## 节点位置校准

双击 `校准500kV节点位置.command` 可打开本地校准页面。页面读取：

- `接线图.png`
- `data/500kv_node_position_candidates.json`
- `data/500kv_node_positions.json`

如需重新从OCR记录生成候选位置，将数据放到 `local_data/ocr-records.json`，或通过环境变量 `SPOTMAP_OCR_DATA` 指定，并确保当前环境已安装可选依赖 `opencv-python`。

## 区域节点分类准备

按用户指定的“珠三角地区（9市）／粤东地区（4市）／粤西地区（3市）／粤北地区（5市）”生成大区、市、拓扑节点三级分类，供后续电价曲线勾选使用：

```bash
.venv/bin/python "500kV断面分析/src/classify_500kv_nodes.py" /path/to/广东500kV节点按市分类.xlsx
```

读取来源表的“各市节点名单”和“补充节点待核验”，按标签查找表头；复用已有拓扑解析与电价节点清理逻辑，保留拓扑原名、A/B/C机组标识和省份后缀。仅使用主表或已核对主表的补充别名归类；多个地市冲突、来源待核验或无法匹配时单列，不从拓扑的接线片区标题或邻接关系推断行政归属。

默认输出 `local_data/区域节点分类/500kv_node_regions.json` 和同目录的 Markdown 核对清单，可通过 `--output-dir` 指定其他目录。结果覆盖节点名单及已确认接线端点的并集；只在名单中出现的节点保留“无接线边”标记。JSON 保留4大区21市的指定顺序、未分类节点、来源工作表／行号及文件摘要，4个用户确认节点使用确认归属并记录确认来源。原表保持不变，生成的业务分类结果留在 Git 忽略目录；曲线界面直接使用已确认的功能配置，无需保留来源工作簿。

## Rust Excel 加速

节点电价清洗的 XLSX 批量读取和新工作簿写出支持 Rust 后端。节点匹配、跨表去重和 Decimal 均值算法继续复用原 Python 实现。界面、命令行和输出文件名不变。

源码环境可选构建（需要 Rust/Cargo，仅构建时需要）：

```bash
.venv/bin/python native/price-xlsx/build.py
```

编译后的程序位于 `500kV断面分析/bin/`，不加入 Git。桌面资源打包时从本次源码重新构建，并纳入文件摘要和升级清单；运行电脑无需安装 Rust。

环境变量 `TOOLBOX_500KV_BACKEND` 支持 `auto`（默认）、`python`、`rust`。默认优先 Rust；缺少原生程序时直接使用 Python，遇到日期／错误单元格或原生调用失败时发出警告并使用 Python 兼容逻辑。严格 `rust` 模式用于验收，不允许回退。Rust 写出使用同目录临时文件，成功后原子替换。

批量传输使用 JSON，内存占用可能高于 Python 流式读取；超大工作簿可指定 `python`。目前加速节点清洗阶段，后续断面计算和网页生成继续使用原代码。

可复现性能比较（所有结果写入临时目录，核对工作簿值／类型／格式、计数及最终 HTML）：

```bash
.venv/bin/python native/price-xlsx/benchmark.py /path/to/节点电价.xlsx --repeats 3
```
