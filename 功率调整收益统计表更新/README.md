# 功率调整收益统计表更新

工具箱“数据采集 → 功率调整收益统计表更新”可选择归湖、鮀莲工作簿，默认更新桌面“日常工作”中的两个原表。文件名必须包含且仅包含 `归湖` 或 `鮀莲` 中的一个名称。

归湖匹配华能（潮州潮安）新能源有限责任公司及华归/归湖场站；鮀莲匹配华能（汕头金平）新能源有限责任公司及鮀莲场站。复用清能统一账号配置，登录态、锁文件和浏览器 profile 均独立保存在本模块目录。

|目标列|来源|单位处理|
|---|---|---|
|C 原始功率|新能源现货基础信息报送 → 生产运行信息 `forecastPower24`|直接使用24点 MW|
|J 申报功率|同页 `stPredictPowerList24`|直接使用24点 MW；未保存时按网站行为读取 `rawShortTermPower24`|
|K 日前电量|新能源现货交易结果 → 出清结果，dataType=1，`electricity`|万kWh × 10 → 模板MWh|
|L 日前电价|同页 dataType=1，`acPrice`|直接使用，与模板价格单位相同|
|M 上网电量|上网电量导出使用的新能源接口 `onlineEle`|直接使用，与原模板一致|
|N 实时电价|出清结果 dataType=2，`acPrice`|直接使用|

六列均按请求运行日期写回同日（无 D-1/D-2 偏移），按 A 列日期及 B 列0–23点匹配到相应月份工作表。日期公式 `=A上一日期行+1` 可在缓存缺失时继续解析，跨入下月的占位块跳过。开始日期留空则检查全部历史空白，截止日期 D 包含当日。

抓取前检查日期覆盖：从明确的开始日期（留空时从模板内首个匹配日期）到截止日期，每天都必须存在完整的0–23点块。缺少日期、月份工作表或中间整日块时，列出缺失日期并停止，不会将部分日期更新后当作全部完成。请先补齐原模板的日期块、合并和收益公式；本工具不自动推断这些公式。

逐单元格跳过非空值（包括0及公式）。接口未发布或含空点的字段保留空白并记录待补；长度非24、日期/场站重复或数值非法则停止写入。只更新空白输入单元格，保留公式、格式、图表和其他 XLSX 部件，并设置 Excel/WPS 下次打开时重新计算。原模板已有公式问题不在本模块内修复。

默认自动备份两个原表，再统一提交并逐格回读数值和数字格式；提交/回读异常会回滚本次替换。抓取期间原文件如被修改则停止提交。运行时解除文件的用户只读权限和 Finder 锁定。

从仓库根目录执行：

```sh
.venv/bin/python 功率调整收益统计表更新/update_power_benefit.py --end-date 2026-10-12
```

可重复使用 `--workbook <路径>` 选择文件，或用 `--start-date` 限定开始日期；`--no-backup` 关闭时间戳备份，`--headed` 显示浏览器，`--login` 单独登录。

## 海风收益表

新增可选工作簿 `~/Desktop/日常工作/海风博弈收益统计-新.xlsx`。默认不勾选海风；勾选后必须明确填写开始日期和截止日期 D，覆盖所选日期（含两端）内的五列已有数值及公式，其他列和日期保持原样。归湖、鮀莲仍执行非空跳过。

|海风目标列|来源|
|---|---|
|C 原始功率|广澳海风场、对应运行日的 `forecastPower24`，24点直接使用|
|R 申报功率|同页 `stPredictPowerList24`，24点直接使用|
|N 上网电量|复用上网电量导出模块的海风 `onlineEle`，与导出 Excel 数值一致，不缩放|
|M 日前电价|出清结果 dataType=1 的 `acPrice`，24点直接使用|
|O 实时电价|出清结果 dataType=2 的 `acPrice`，24点直接使用|

公司匹配华能广东汕头海上风电有限责任公司，场站匹配广澳海风场；使用原模块独立登录态。支持 `10月份` 和 `10月` 等月份页，按 A 列日期、B 列小时定位，无日期偏移。缺失或未完整发布的字段保留原值（含公式），日志标明未更新；覆盖共享公式主单元格前展开同组引用，避免未发布的实时字段出现失效引用。写后回读数值、数字格式及样式；默认备份并统一提交。

```sh
.venv/bin/python 功率调整收益统计表更新/update_power_benefit.py \
  --workbook "$HOME/Desktop/日常工作/海风博弈收益统计-新.xlsx" \
  --start-date 2026-10-16 --end-date 2026-10-21
```

海风需通过 `--workbook` 显式选择，不改变原来不带工作簿参数时的归湖、鮀莲默认行为。
