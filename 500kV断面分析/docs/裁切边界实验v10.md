# 粘连标签裁切边界实验 v10

状态：2026-11-07 实验快照。操作以[模块 README](../README.md)为准；模型、底图、词库或参数变化后重新验证。会话目视对应不是独立人工真值。本轮按普通研发任务执行。

## 依据与实现

局部诊断实际调用 PP-OCRv6_medium_rec 30 次。过紧的“储能站”裁切在彩色、灰度下都高置信误读为“诸能站”；补足边界后六次正确。说明两次一致及高置信本身不足以证明文字正确。“润洲B厂”粘入线路编号，旧提案只保留到 B，常规横向留白还会带入编号 0。

本轮先实施边界清楚的粘连标签修复：母线字母后保留电厂／厂／站；普通复读失败后，最多追加三个边界范围，分别不加横向留白、左右移动估算中文字宽的 12%。每个范围均须彩色、灰度两次读出同文、置信度≥0.9且对应唯一站名；出现其他站名的高置信证据立即暂缓。保存原文、来源框、实际裁切范围及所有已执行复读。双行设施名组合及非圆形符号尚未接入，不用手选裁切替代自动发现。

OCR 缓存配方为 `native1500-retry2x-native-label-boundaries-v6`，算法为 `station-ownership-label-boundaries-v10`；可实际升级 v5 缓存，不重新运行原图检测。GUI 与 CLI 使用同一公共实现。
