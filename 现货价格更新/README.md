# 现货价格分析表更新

工具箱“数据采集 → 现货价格分析表更新”。按日期区间抓取华能广东公司交易辅助决策系统“新能源现货交易结果”的 24 个整点日前、实时出清电价，写入所选场站的现货价格分析工作簿。

## 使用

1. 勾选要更新的场站（归湖／鮀莲／海风），默认不勾选，至少选一个；所选场站不能指向同一个工作簿。
2. 确认各场站工作簿，默认位于 `~/Desktop/日常工作/`：
   - `2026年现货价格分析（2026.8.14更新）-归湖.xlsx`
   - `2026年现货价格分析（2026.8.14更新）-鮀莲.xlsx`
   - `2026年现货价格分析-海风.xlsx`
3. 填写“更新日期”范围，默认 D-1 至 D；点日期框弹出左右双月历，左侧选开始、右侧选结束，可取消翻月联动独立翻页。
4. 按需调整“覆盖非空单元格”（界面默认勾选）和“写入前生成时间戳备份”（界面默认不勾选，命令行默认生成）。
5. 点击“抓取并更新”，在页面日志查看每个场站、每种价格的写入结果。

## 写入与校验

- 日期取数据源中的同日日期，在目标工作表 A 列匹配，按 0—23 时顺序写入 `B:Y`。
- 日前与实时逐日独立更新：只有完整 24 点才写入；缺失、点数不足或无效值时只跳过该日期和该价格类型，保留原单元格。
- 默认覆盖已有价格，`--skip-existing` 可跳过已有非空价格。
- 完整价格日期超出工作表末日时，从表尾下一日连续补齐 A 列日期，沿用原日期格式、单元格样式和行高，再写入 `B:Y`；中间没有完整数据的新增日期保留空价格，不填零。
- 各场站、日前和实时表分别按自己的末日接续；历史区间缺行、重复日期、表尾有其他内容或接续区域含合并单元格时停止写入，避免错位覆盖。
- 保存采用同目录临时文件原子替换，保存后重新打开回读 24 个值与数字格式。

## 命令行

```bash
.venv/bin/python 现货价格更新/update_spot_prices.py --start-date 2026-11-01 --end-date 2026-11-02
.venv/bin/python 现货价格更新/update_spot_prices.py --start-date 2026-11-02 --stations 海风
.venv/bin/python 现货价格更新/update_spot_prices.py --login
```

`--stations` 可选 `归湖`、`鮀莲`、`海风`，不传时更新三个场站；`--guihu-workbook`、`--tuolian-workbook`、`--haifeng-workbook` 覆盖默认路径；`--dry-run` 只抓取校验，`--skip-existing` 跳过已有价格，`--no-backup` 关闭时间戳备份。

## 配置与登录态

`现货价格更新/config.json` 只支持 `headless`（命令行是否隐藏浏览器）。复用清能统一账号；登录态、锁和 `.browser-profile/` 独立保存在本模块目录，与其它工具互不影响。
