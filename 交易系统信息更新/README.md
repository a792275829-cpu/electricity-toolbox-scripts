# 交易系统信息更新

按来源日期匹配日前 D、实际 D-3，写入 `Sheet1`。保留当前分类顺序、最大／最小／平均／总电量四项字段及原有单位换算。

开始日期留空时，先定位符合当前模板布局的最早缺值日期组，逐格补空；已有数值（含零）和公式保持原样，然后从最后日期组继续追加。明确填写开始日期时，必须与该待更新日期一致。历史不同分类布局不套用当前映射，最新模板组仍严格校验。

接续时按行号复用或插入目标行，保留未更新的行和工作表维度，避免表尾预留格式行导致重复行号。新增日期组沿用模板行及合并格式；目标区域有非日期组的内容或合并冲突时停止，保留原文件。已有日期组只写缺值，不重复追加日期。

沿用同目录临时工作簿、备份和提交回滚流程。保存后回读日期、字段顺序和新增数值，并回读原有单元格的数值／公式和数字格式；外部程序同时保存时停止提交。登录态、profile 和锁继续由本模块独立维护。
