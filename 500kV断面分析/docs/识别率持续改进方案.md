# 拓扑初标识别率持续改进方案

状态：v3历史实验快照。2026-11-07 的 v3 首轮改进已实施；这是一份实验方案与测量记录，不代表全图准确率。后续版本见[拓扑Goal运行记录](拓扑Goal运行记录.md)。操作入口见[模块README](../README.md)。模型、底图、评分或样本发生变化后须重新验证，不能沿用本页数字。

## 决策

继续使用 PP-OCRv6_medium。先补文字检测遗漏与站点符号定位，再根据剩余错误决定是否需要训练专用检测器。仅重复跑同图、同模型、同参数不会形成新的改进证据。跨电压同名、缺少正确符号候选时保持未决；保留逐站接受、移动或拒绝，线路仍按原流程核对。

## 本轮可复现流程

1. 使用2026-07-20原始节点电价表、7111×5025原图；不改原工作簿、原图和已有草稿。
2. v2基线固定为提交 `72300ce` 的公共匹配／圆点逻辑，使用其真实OCR结果。v3复用该图同模型初次文字记录，实际执行本机文字框补查和PP-OCRv6局部复读，不声称重新跑过全图检测。
3. v3新增5条经PP-OCRv6两次确认的文字记录；其中李朗、宝安在旧20站，侨乡在新20站。保留来源及复读证据。缓存处理版本为 `native1500-retry2x-native-proposals-v3`，旧视觉编号选择不能套用。
4. 新验证集按旧站名清单图块密度分7／7／6站，随机种子20261107，排除旧20站。名单及核心代码摘要在查看结果前锁定。
5. 不再据新验证集调参数。本轮新验证集逐图进行会话视觉核对；若下一轮利用其失败案例，它转为回归集，必须另取未使用样本验证。

以上“对应正确”是当前会话对原图与候选位置的视觉判断，不是独立人工电压／像素真值，不代表全图准确率；没有调用在线Qwen／Gemini视觉接口。自动候选不能直接接受或用于确认线路。

## 持续循环及退出标准

每轮执行：分析逐站错误 → 选一个可检验改进 → 实际OCR／算法实验 → 锁定新验证集评估 → 运行相关回归及备份回读 → 更新证据与下一步。模型权重、初次OCR缓存和新增局部推理须分开记录；不能把缓存回放或会话观察伪称为在线模型调用。

持续目标以新的不少于30个220kV样本和一组500kV回归为准：站名匹配≥95%、候选对应正确比例≥95%、候选覆盖≥80%，且不回退已证实正确案例。达不到就继续迭代；没有独立人工真值时不能声称严格准确率达标。需要外部服务或真值时，明确证据与缺失条件，不猜测、不绕过既有保护。

本轮原始结果位于Git忽略的 `local_data/准确率改进v3/` 和 `local_data/自动初标20站_220kV/准确率改进v3/`；包含固定清单、版本锁定记录、逐站对照图、报告、HTML与待核对JSON。后续任务以最新源码及这些证据为起点，不覆盖历史实验输出。
