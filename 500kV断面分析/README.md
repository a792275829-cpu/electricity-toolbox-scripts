# 500kV断面分析

广东 500kV 节点电价清洗、断面识别与交互式拓扑网页生成。日常使用从工具箱侧栏“分析与报告 → 500kV断面分析”进入，也可用本目录的独立窗口或命令行。

批量运行前统一检查所有输入和输出文件名。不同目录的同名文件，以及仅大小写或 Unicode 组合形式不同的名称，可能指向同一个结果网页；遇到这种冲突时整批停止，不覆盖已有结果。请更改输入文件名或分批选择不同输出目录。

## 判定规则

同时满足以下三条才记为断面：

1. 相邻节点价格一涨一跌；
2. 两端价差严格大于阈值（默认 80 元/MWh，必须 ≥ 0；网页内可随时调整，见下节）；
3. 条件连续满足至少 4 个时点。

网页颜色由累计触发时点与最大价差共同决定：持续越久、价差越大，颜色越深。节点与线路的电价曲线支持悬停或点按逐时读数，缺失数据显示“暂无数据”。

## 使用

工具箱页面：

1. 添加一份或多份节点电价 `.xlsx`。
2. 确认拓扑名单为 `500kV断面分析/500kV节点拓扑.md`；只有换用另一份已校验拓扑时才修改。
3. 选择结果目录，默认 `~/Downloads`。
4. 点击“开始分析”。每份输入在所选目录生成一个 `<原文件名>_500kV分析.html`，成功后自动用默认浏览器打开；“打开结果目录”可查看输出。价差阈值在结果网页内调整，初始值为 80 元/MWh；工具箱和独立窗口无需预先设置。

命令行：

```bash
.venv/bin/python "500kV断面分析/run_500kv_analysis.py" \
  --output-root ~/Downloads --threshold 80 /path/to/日前节点电价查询.xlsx
```

可以一次传入多个 Excel，每份输入生成一个网页。也可双击 `500kV断面分析/500kV 断面分析.command` 使用独立窗口。

## 处理流程

1. 从内置拓扑的已确认连线端点生成 500kV 节点白名单。
2. 匹配数据源节点别名，先排除明确标为 220kV、110kV 等非 500kV 的母线；名称含多处电压时按最后一处母线电压判定（如“500kV东莞变220kV”属于 220kV）。同一拓扑节点、同一数据项有明确 500kV 记录时，仅对这些记录逐时取平均，不混入无电压标记的记录（如回隆变 M21）；没有明确 500kV 记录时，保留既有无电压别名取数，其真实电压仍需人工核验。不以低压侧或无电压记录填补已有 500kV 曲线的空值；仅有非 500kV 记录的节点显示“暂无数据”。
3. 按上节规则识别断面，逐时点累计触发情况。
4. 清洗结果与断面明细只在临时目录使用，生成网页后自动删除；原始工作簿不会被覆盖。

## 输出

- `<输出目录>/<原文件名>_500kV分析.html`
- 中间清洗 Excel、断面明细 Excel：临时文件，完成后删除

网页内嵌全部数据与脚本，离线可用。断面导航默认按最大价差从高到低展示，可切换为按严重度或累计时点排序。界面固定浅色；图上方工具栏左侧为价差阈值输入框（“重置”回到生成时的默认值，右侧同步显示触发断面条数），右侧依次为分析模式、潮流查看、放大、缩小、重置、节点搜索；修改阈值后页面按原始节点电价重算断面判定，线路颜色与粗细、节点阻塞标记、时间轴色带、断面导航列表同时刷新，不需要重新生成文件，输入框失焦或回车生效、清空或负数会退回上一个有效值。时间轴为 00:00—23:45 共 96 格，拖动或用方向键切换时点，全图用双箭头表示该时点潮流方向（低价 → 高价），阻塞线路用红色。箭头速度按“该线路长度／全图中位线路长度”的平方根调整，判定为断面的线路取普通速度的一半；关闭图层、切换视图或页面进入后台时暂停，系统开启“减少动态效果”时保持静态方向。

开启工具栏“分析模式”后，可在地图上多选节点和线路，接线图铺满页面，电价曲线在背景透明度为 95% 的悬浮框内叠加显示；共用节点只显示一次。拖动标题可移动曲线框，标题聚焦后也可用方向键移动（Shift 加速），窗口缩放时保持在可视范围内。再次点击节点或线路可取消，也可在已选清单逐项移除或点击“清空已选”。鼠标在曲线图内移动或点按时，读数框跟随指针，竖向显示时刻和各节点的颜色、电价；较长的读数列表可在曲线区用滚轮滚动，移开指针后隐藏，框底部不再常驻图例和时间说明。缺失时点保留断点，读数显示“暂无数据”。关闭分析模式恢复右侧栏和单选查看。选择仅保留在当前网页会话中。

界面过渡仅用于交互反馈：分析模式切换和地图布局约 200ms，按钮缩放、重置及搜索定位约 220ms，视图切换约 160ms；新增曲线淡入 140ms、移除淡出 90ms，不插值生成中间电价。读数框只在出现／隐藏时短暂淡入淡出，鼠标跟随、曲线读数、时间轴和拖动直接更新。系统开启“减少动态效果”时关闭这些过渡；开始拖动可立即中断地图视角动画。

页面左侧可在“潮流分析／区域电价分析”之间切换。区域视图按“大区 → 市 → 节点”三级勾选，提供逐时读数、导出当前可见曲线的 CSV，以及日均价前 10／倒数 10 排名。

按标签查找表头，复用拓扑解析与节点清理逻辑，保留拓扑原名、A/B/C 机组标识和省份后缀。多个地市冲突、来源待核验或无法匹配时单列，不从接线片区或邻接关系推断归属。默认输出 `local_data/区域节点分类/500kv_node_regions.json` 与同名 Markdown 核对清单，`--output-dir` 可改；结果留在 Git 忽略目录。

## Rust Excel 加速

节点电价清洗的 XLSX 读取与写出支持 Rust 后端，节点匹配、跨表去重与 Decimal 均值仍用 Python。源码环境构建（需要 Rust/Cargo，仅构建时需要）：

```bash
.venv/bin/python native/price-xlsx/build.py
```

产物在 `500kV断面分析/bin/`，不入 Git；桌面资源打包时从本次源码重新构建。环境变量 `TOOLBOX_500KV_BACKEND` 可选 `auto`（默认，优先 Rust，缺程序或原生调用失败时退回 Python 并告警）、`python`、`rust`（严格，不回退）。批量传输用 JSON，超大工作簿可显式选 `python`。性能对比：

```bash
.venv/bin/python native/price-xlsx/benchmark.py /path/to/节点电价.xlsx --repeats 3
```

## 500／220kV 节点人工校对

可将当前本机校对底稿生成独立 HTML，双击后离线使用（含底图与候选数据）：

```bash
.venv/bin/python "500kV断面分析/tools/build_layer_review_html.py" --output ~/Downloads/500和220kV节点校对平台.html
```

生成命令不会覆盖已有 HTML；需要更新时请指定其他输出路径。HTML 点击“保存本项”后将结果保存在当前浏览器；请经常点击“导出结果”备份 JSON，换电脑或浏览器后可通过“导入结果”恢复。导入前请先导出当前进度，导入会替换该浏览器中的校对数据。浏览器清除站点数据可能删除未备份进度。HTML 中的修改不会自动写回本地服务版的 `review.json`；后续接入请使用导出的 JSON。


双击 `校对500和220kV节点.command` 打开本机校对页面。左侧可搜索原图名称、候选电价名称和分片；右侧可修改规范名称、电压、逐行填写电价原始名称、标记映射状态并填写备注。滚轮缩放、拖动平移、点击底图选择坐标，检查后选择坐标状态并点击“保存本项”。切换节点前请保存。来源的强／弱匹配、线路名称和分片仅为线索，均须人工核验；确认映射时必须明确电压和原始名称。坐标为空的节点仍可搜索编辑。

带位置线索的 HTML 可筛选“有位置候选”，选择节点时自动放大到候选点；无候选时跳到名称所属图块，多个图块可切换。位置候选分别注明原 500kV 锚点、原校对标记和 OCR 文字框；橙圈／框是查找线索，红圈是准备保存的坐标。OCR 文字框不允许直接当节点坐标，请在底图上点击实际节点并确认。来源标记与所属图块不一致时有提示，必须对照原图核验。修改后点“保存本项”，定期导出 JSON；新页面可导入旧版导出结果，已有编辑字段不会被位置候选覆盖。

需重建候选时，原工作包的 `work/tiles` 包含 30 张 1500×1250 切块，`work/platform_items.json` 含原校对标记。macOS 安装 Xcode Command Line Tools 后可执行：

```bash
.venv/bin/python "500kV断面分析/tools/run_layer_review_ocr.py" /path/to/work/tiles --output /path/to/vision_ocr.json
.venv/bin/python "500kV断面分析/tools/prepare_layer_candidates.py" --pins /path/to/work/platform_items.json --vision /path/to/vision_ocr.json --output /path/to/candidates.json
.venv/bin/python "500kV断面分析/tools/build_layer_review_html.py" --data /path/to/candidates.json --output ~/Downloads/节点校对_新.html
```

工具仅把候选附加到校对副本，不修改已有坐标及确认状态；OCR 结果、数据和 HTML 均为本地产物。

校对结果保存在 `local_data/分层拓扑校对/review.json`（桌面开发环境遵循 `TOOLBOX_DATA_ROOT`）；请备份该文件。首次在其他工作区使用时，先从来源工作包导入 `过程数据/mapping2.json`：

```bash
.venv/bin/python "500kV断面分析/tools/layer_review_server.py" --import-source "/path/to/mapping2.json"
```

导入不会覆盖已有校对结果。校对数据目前仅供人工编辑和后续接入，不参与现有 500kV 分析，也不会自动生成 220kV 曲线或线路；同站多电压节点拆分和线路校对仍待实现。请勿将来源候选或图上位置直接视为已确认连接。

## 浏览器编辑

入口为工具箱“500kV断面分析 → 浏览器编辑”，在默认浏览器打开本机HTML编辑器。保持工具箱运行才能读取电价表和保存；资源不依赖外部网站或CDN，不能直接双击 `index.html` 使用。首次在新Mac使用时导入底图，或导入包含底图的JSON备份。已选择一份电价表时自动读取该表，也可点击“导入电价表”。

### ① 标注站点

导入接线图PDF或PNG／JPG／WebP图片。PDF支持单页、整页为一张图片且未旋转的类型；多页、纯矢量或混合排版PDF先导出为图片。PDF内原始JPEG／PNG直接提取，不重新压缩或缩小。底图只保存在本机应用数据目录，不加入发行源码。

左侧默认显示未标注站点，按500kV／220kV分类，可搜索站名。选择站名后，在底图对应位置单击完成标注；“连续标注”默认开启，完成后选择同电压的下一站，保持当前视野。“跳过，下一站”只跳过本次操作，不删除节点。拖动空白平移、双指滑动平移、捏合缩放；拖动标记调整位置，双击左侧已标节点或点“放大所选”定位。重新定位可选左侧节点后再点底图，“取消所选站点标注”可清除位置；均支持撤销。

同站同电压的不同价格节点共用一个底图标记，列表内仍独立保留电价曲线；标注同站位置不会合并电价或自动复制连接。不同电压分别标注。此阶段不叠加整张拓扑线路，避免遮挡原图。属性区在选中站点或线路时展开，可收起；页面基础字号17px，节点库加宽，备份／加载及节点清理折叠显示。

#### 自动初标与30站小样

左侧选择中文OCR和可选视觉复核，再点“自动初标 · 30站小样”。本机Vision是对照基线；PP-OCRv6_medium分别使用同名检测、识别模型。原图按1500×1500像素分块、重叠300像素，检测长边上限显式为1500，避免默认缩放丢失小字。对低置信站名及与词表相差一字的三字以上疑难文字，最多复识别120个文字框，比较两倍彩色与灰度增强版本；保留原文及坐标，只有两种处理均高置信匹配同一站名时才允许补充匹配。短站名不做一字强制纠错；多次结果指向不同站名时留给人工核对。

PP-OCRv6记录每个首轮图块的原图范围、缩放比例和逐视图文字证据。距块边100px内的文字列为边缘风险提案（不等于已截断），优先复用能覆盖文字及周围120px上下文的相邻原图块，再复用已补裁视图；不足时从无损原图居中补裁，每轮最多12次新增局部检测。中文标签优先，当前仅追加一个居中视图，不追加另一方向视图；原图边缘缺少上下文时记录未决原因，不补造图外信息。符号检测直接使用整幅原图，不因符号归属不明反复OCR。100px、120px及12次预算是当前图上的实验参数，不代表已验证适用于其他底图。

跨块同文近位置合并时保留全部来源；已有同文框保持定位，新增框仍作为逐视图原始证据；节点库已有后缀变体在30px内按同一位置评估，不将同地全称／简称误报为多位置。完整标签与碎字的差异保留在 `view_disagreements`，不同有效站名则标记冲突并暂缓，仍须检查同名唯一性、设施类型及符号归属。旧缓存的块来源仅按几何包含关系推定，明确标为 `inferred-legacy-containment`；不能称为原始逐块模型证据。v7缓存升级只运行边缘补裁，不重跑此前文字组合步骤；v8缓存回放不计新推理，报告分开记录本次新增检测次数、缓存来源及运行时间。

PP-OCRv6对仍未匹配的站名启用本机Vision文字框补检。补检仅提供裁剪范围，须再经PP-OCRv6对两倍彩色与灰度图各复读一次，两次同文、置信度均不低于0.9且精确对应唯一站名，才补入识别记录；不直接采信Vision文字，不做短站名一字强制纠错。若本机OCR无法启动，保留PP-OCRv6原结果并报告补检警告。

本机文字框置信度低至0.3时也可作为补检提案，但最终接纳条件仍是PP-OCR两次均≥0.9、同文且对应唯一站名。相邻碎字可横向并框后整词复读，固定留白3px；相邻上下两行仅对“储能站／光伏电站”后缀提出组合，逐行彩色、灰度复读后组合完整原文，留白6px。保留分行证据，匹配索引只使用完整站名，不把设施名的一行当作独立站名。每轮最多复读80个组合提案；包含设施后缀的混合高框最多16处局部两倍放大重检，检测结果仍需复读确认。

母线字母旁粘入数字或相邻站名时，可按A／B／Y边界、中文后的数字或字母加数字边界提出裁剪；粘连中文段须先确认两部分都能唯一对应节点库站名，且完整文字不是已有站名，才尝试分开，支持段外带编号或母线字母。提案必须经原图彩色、灰度两次高置信精确复读才追加，保留原OCR、原框和提案来源；提案框不能当节点坐标。“光伏电站／光伏电／光伏”匹配保留光伏类型，不据此合并普通同名站。

粘连标签裁剪保留母线字母后的“电厂／厂／站”完整后缀。常规留白复读失败时，最多追加三种横向边界提议（不加横向留白、按估算字宽左右偏移12%），每个范围仍须彩色、灰度两次高置信同文；遇到指向其他站名的高置信证据立即暂缓，不继续挑选有利结果。识别记录保留实际裁切范围及每次复读；边界搜索仅用于粘连文字提案，不修改站名词库或人工标注。

220kV可补充两个分离半圆瓣的符号提案：必须同时满足封闭内部、颜色、面积、方向及镜像偏移证据，锚点取两瓣对称中点，不作为圆心拟合误差统计。圆点归属竞争时，只有厂名对应范围内唯一、黑环完整且内部为单条正弦发电机笔画，并且没有同样接近的其他站名或强未拟合符号，才允许提出独立发电机候选；仍有竞争时保留未决。符号形状不用于推断电压，所有新增提案仍须逐站接受、移动或拒绝。

220kV光伏站名在无视觉复核时，所选候选还须具备四个相近四边形面板单元的图符证据；没有一致证据就暂缓，不直接采用附近风电符号，也不自动改选第二近符号。文字识别成功不等于节点定位成功。

圆点先由霍夫变换产生候选，再按圆周梯度拟合圆心；220kV候选同时补充黑色闭环内部轮廓，优先考虑文字距离、完整黑环和圆周证据，避免把符号内部填色饱和度当作可靠性。黑环仅作为当前图上的排序线索，不据此判定电压；角度覆盖不足、拟合漂移或圆点候选得分接近时需要视觉或人工核对。可选视觉模型同时接收带编号的局部图与未标记上下文图，只选择已有候选编号或返回无法判断，不产生坐标。同名多位置、跨电压无法区分时仍由人工定位。视觉复核结果也仅为初标。

若更近的位置存在圆周支持较强、但圆心尚未可靠拟合的符号，自动流程不以远处完整圆点替代本站，也不直接接受该未拟合坐标。视觉复核先排除低支持的文字／交叉线伪圆；高支持的部分符号仅作为视觉复核候选，仍须逐站接受。

初标显示为“待核对初标”，可逐站接受、拖动修正或拒绝，支持撤销、保存和带图备份。接受前不计入已标注，也不用于生成简图或应用到分析；接受站点不确认线路。已有人工标点、初标和线路确认状态均保留。

自动初标需要在工具箱源码环境可选安装 `opencv-python-headless`（`.venv/bin/python -m pip install opencv-python-headless`），普通分析无需安装。PP-OCRv6同样是可选依赖，可在独立Python环境安装 `paddleocr==3.7.0`、`paddlepaddle==3.3.1`、`opencv-python-headless` 和 `openpyxl`，首次使用需联网下载模型；模型和环境仅保存在本机。默认发现当前数据根目录的 `500kV断面分析/local_data/模型环境/ppocr/bin/python`；也可显式指定解释器，再启动现有调试入口：

```sh
TOPOLOGY_OCR_PYTHON="$PWD/500kV断面分析/local_data/模型环境/ppocr/bin/python" ./00_启动/源码调试版.command
```

环境中设置 `TOPOLOGY_VISION_MODEL`、`TOPOLOGY_VISION_BASE_URL`、服务要求的 `TOPOLOGY_VISION_API_KEY`，再选择Qwen或Gemini。地址须为HTTPS或本机HTTP，不含内嵌凭据。未配置时选“未配置，仅 OCR＋圆点”；这不代表已做视觉复核。凭据不写入源码、草稿或报告。OCR／视觉请求失败不会提交部分初标。

Qwen兼容的本机服务可使用 `http://127.0.0.1:<端口>/v1`，回环请求直接连接本机，不经过系统代理；不修改其他工具的代理设置。报告按实际发出的请求区分本机与远程调用，候选被过滤后未发请求的不计调用。服务与模型需另行准备，普通分析和OCR不依赖它们；本机模型试验结果见运行记录，不将已下载权重或会话选择文件当成模型已推理的证据。

独立小样命令不读取或保存现有编辑草稿，生成 `report.json`、`ocr.json`、`30站小样.png` 和可直接导入编辑器的 `待核对初标.json`。输出目录必须不存在；试验数据根目录也须独立指定：

```sh
TOOLBOX_DATA_ROOT="$PWD/logs/topology-prelabel-trial-data" \
  .venv/bin/python 500kV断面分析/tools/run_topology_prelabel.py \
  --prices '/绝对路径/节点电价表.xlsx' --image 500kV断面分析/接线图.png \
  --output-dir '/绝对路径/新的小样目录' --ocr-engine ppocrv6 \
  --sample-file '/绝对路径/固定30站.json'
```

使用独立模型环境时，命令前同时设置 `TOPOLOGY_OCR_PYTHON`。固定清单是JSON数组，每项形如 `{"station":"站名","voltage":500}`，站名须与电价表解析后的节点库一致；同一清单用于所有对照，包含OCR漏识别站点。推荐按人工基准位置的稀疏、中等、密集区域各取10站。`--baseline` 关闭疑难复识别与圆心拟合；增强版可用 `--ocr-cache` 读取同图、同引擎、同处理版本的缓存，或读取基线／v2／v3／v4／v5／v6缓存后实际补做复识别、漏检文字框补查及粘连标签复读，不重新跑整图检测。旧缓存升级会输出新的处理版本；旧版本的视觉编号选择不能套用到新候选。`--vision qwen`／`--vision gemini` 启用已配置的视觉复核。

未提供固定清单时，按OCR结果密度及未识别站名抽样，仅供探索，不能据此计算全图准确率。报告分开列出站名词表匹配、未决、初标、视觉复核数量，以及同底图已有500kV人工锚点的像素偏差；锚点仍须复核，超过30像素仅标为疑似错配。联系表中橙圈为初标、蓝十字为已有锚点、粉框为OCR位置。匹配数不等于识别准确率；无人工真值、无可比锚点或未调用视觉模型时，不报告相关准确率。

已在当前会话或其他离线流程核对过编号图块时，小样命令支持 `--review-decisions '/绝对路径/视觉复核选择.json'`；不能同时指定在线 `--vision`。复核文件记录底图摘要、处理版本，以及以 `[站名,电压,OCR记录ID]` 的JSON字符串为键的 `choices`；每项包含完整圆点候选列表的SHA-256摘要 `circle_signature` 和选择的 `index`（无法判断为 `null`）。辅助函数位于 `toolbox_shared.section_vision_review`。候选位置、顺序或尺寸变化会拒绝回放，不能用复核文件注入新坐标。报告注明复核来源及未调用在线API；本地复核也不自动接受标点。与已有锚点相差超过30像素的交付初标附带警示，在编辑器属性区提示重点核对。

持续改进方案、评估口径和本轮样本限制见 [识别率持续改进方案](docs/识别率持续改进方案.md)。

自动选点遇到其他站名竞争时，只有另一站也以至少0.04的分差首选同一个已拟合圆点，才将目标留为未决；不因附近存在文字就拒绝，也不改选次优圆点。受保护的已标注站点仍参与归属检查，标点和线路不变。OCR精确匹配支持A／B／Y及两字母组合母线后缀（如盘允BY），不做短站名一字强配。

小样命令同时生成离线 `核对报告.html`，记录算法版本、OCR缓存／实际推理来源和在线视觉调用状态，附逐站结果、原图裁剪与待核对JSON下载。持续Goal本轮评估与限制见 [拓扑Goal运行记录](docs/拓扑Goal运行记录.md)。

### ② 核对连接

已有线路作为待核对项，不因标点自动确认。选择站点后，右侧列出相连节点及确认状态；选择一条连接会定位两端，画布只突出当前站点关联线路或当前线路，待核对线路为虚线。“下一条待核对”选择两端均已标注的待核对线路；未标注的端点需先完成标点。

核对两端和连接类型后点击“核对并确认此连接”，在确认框中再次点击“确认连接”才生效。取消不改变数据；错误连接可删除，已确认连接可撤回确认。新增连接先选起点，再在左侧或图中选终点，预览后同样二次确认。跨电压连接须明确选择“站内变压器”；修改连接类型后需要重新核对。

### ③ 生成简图

至少标注一条连接的两端并确认该连接后，点击“生成简图”。底图隐藏，只显示已标注的有效站点及已确认连接；尚未标注或未确认的关系不进入新简图。首次按底图相对位置布局，同站多价格节点分开放置；可拖动简图节点微调。底图标注坐标与简图坐标独立，拖动、重新生成简图均不改变底图标点。重新生成保留手动调整的位置，“按底图重新排版”经过确认后才覆盖这些手动位置，支持撤销。

简图的节点大小、站名字号和线条粗细随缩放同比变化；全图站名字号18px，工具栏有“＋／−”“全图”“放大所选”。标点及核对阶段的标记保持适合点击的尺寸范围，底图站名随图片一起放大。新标点、价格同步、属性修改或连接确认后，重新生成简图再应用。

“保存草稿”保存所有阶段的编辑；“应用到分析”保存独立快照并切换模块拓扑路径，后续草稿修改须再次应用。分析仅使用已标注、已确认、已定位的有效500kV站间线路；220kV和站内变压器保存在编辑器内。没有底图的旧JSON仍可查看和使用原有简图；导入底图后保留旧简图位置和线路，重新完成标点、核对再生成新简图。

### 电价同步与备份

- 电价表跨工作表读取“节点名称”和分时时点表头，按站名、电压、完整曲线去重。同站不同电价保留多个节点，缺失时点不同也不合并；不保存全部原始名称，仅保留身份摘要。电压按名称最后一个电压标记识别，无电压归入待确认，其他明确电压不导入。日期沿用文件业务日期，不做D／D-1转换，不改原工作簿。
- 新Excel匹配成功的节点更新曲线并保留标点、简图位置及连接；新增站点进入未标注列表，同站新价格在位置唯一时可共用已有标点，连接仍独立。减少节点标记缺失，保留拓扑，再出现时恢复。同步展示新增、更新、缺失和待对应数量；清理缺失节点须确认节点及关联线路数量，支持撤销。
- 多价格节点优先按唯一身份摘要匹配，再比较相同时点的完整曲线；无法唯一对应时保留旧节点及线路，新曲线标记待对应。右侧“对比同站价格”按时点对齐、标出差异，可“对应此旧节点”保留位置和连接，或“确认为独立新增节点”；不按价格接近程度猜测、不求平均。
- 显示名、人工地市和电压分类可修改；显示名不作为同步身份键。“保存草稿／应用到分析／导出备份”也会提交当前节点属性输入。分析名称不能包含连字符、逗号、顿号、冒号或换行。每次分析重新读取输入Excel；无法唯一对应的500kV多价格节点须先处理。
- “备份与加载 → 导出备份”生成包含底图原始图片、标点、简图布局、线路核对状态及曲线的JSON，可在另一台Mac导入。仅导入不自动覆盖本地草稿，检查后再保存。更换不同底图须确认，会清除底图标点和线路确认状态，保留节点、连接和简图布局，可撤销。
- 多个网页同时保存采用版本检查；过期页面先导出备份再加载已保存数据。关闭网页前保存或导出，未保存时浏览器提示，关闭工具箱也会检查。服务停止后仍可导出已载入节点数据，但备份可能无法附带底图；恢复时需重新导入同一底图或完整备份。

草稿继续使用应用数据目录下的 `local_data/拓扑编辑/catalog.json`，已应用快照为同目录 `applied.json`；底图资源在同目录 `basemaps/`，默认底图引用为 `basemap-default.json`。桌面和源码调试环境遵循 `TOOLBOX_DATA_ROOT`，已有草稿不被初始化覆盖。“拓扑名单”支持原Markdown和JSON，JSON也可传给批处理入口的 `--topology`。自动化使用独立无界面浏览器验证操作流程和保存回读，实际触摸板手感由用户核验。
