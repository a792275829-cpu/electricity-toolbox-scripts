# 电力工作工具箱 macOS 版

这是一个面向 macOS 的电力业务桌面工具集合。统一入口为 Tkinter 图形界面，当前集成 15 个工具，包括上网电量导出、风力预测截图、市场表更新、现货价格分析表更新、交易系统信息更新、功率调整收益统计表更新、广东电价预测、电力交易分析、500kV断面分析、广东运行日报解析上传、南方分公司电力市场日报、出清结果汇总上传、生产经营报告生成、集团每日数据上传和 WPS/KDocs 写入。

仓库公开地址：[a792275829-cpu/electricity-toolbox-scripts](https://github.com/a792275829-cpu/electricity-toolbox-scripts)

## 环境要求

- macOS 12 或更新版本
- Python 3.11 或更新版本
- Google Chrome，用于网页登录、上传和 WPS/KDocs 流程
- Node.js 18 或更新版本，仅“出清结果汇总上传”的上传功能需要
- 能访问相关业务系统的网络环境；如公司网络要求代理或 VPN，请先连接

项目使用根目录下的 `.venv` 作为 Python 环境。不要把系统 Python 或个人电脑上的绝对解释器路径写入项目配置。

## 首次安装

### 1. 获取项目

使用 Git 克隆：

```bash
git clone https://github.com/a792275829-cpu/electricity-toolbox-scripts.git
cd electricity-toolbox-scripts
```

也可以从 GitHub 下载 ZIP，解压后进入项目根目录。

### 2. 解除 macOS 下载限制

从网页下载的项目可能带有隔离属性。首次使用时在项目根目录执行：

```bash
xattr -dr com.apple.quarantine .
chmod +x setup_macos.command "00_启动/电力工具箱.command" \
  "wps自动/启动WPS专用Chrome.command"
```

### 3. 自动安装依赖

在项目根目录运行：

```bash
./setup_macos.command
```

安装脚本会完成以下工作：

1. 创建项目专用 Python 环境 `.venv`。
2. 安装 `requirements.txt` 中的 Python 依赖。
3. 安装 Playwright Chromium。
4. 检测 Node.js/npm；如果存在，则安装私有数据上传工具的 Node 依赖。
5. 修复工具箱和 WPS 专用 Chrome 的 `.command` 启动权限。

如果暂时没有 Node.js，其他 Python 工具仍可使用，只有“出清结果汇总上传”的上传功能不可用，汇总仍可使用。安装 Node.js 后执行：

```bash
cd "电力工具脚本/private-data-uploader-tool"
npm install
```

### 4. 手动安装命令

只有自动安装失败时才需要使用以下等价命令：

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python -m playwright install chromium

cd "电力工具脚本/private-data-uploader-tool"
npm install
```

## 启动工具箱

在 Finder 中双击：

```text
00_启动/电力工具箱.command
```

也可以在项目根目录从终端启动：

```bash
./00_启动/电力工具箱.command
```

启动器使用 `.venv/bin/python`。如果 `.venv` 或关键依赖缺失，会自动调用 `setup_macos.command`。

启动后默认显示“今日概览”：

- 左侧按“数据采集”“分析与报告”“上传与写入”分组。
- 工具页面首次打开时加载，切换页面不会清空当前状态。
- 右侧任务中心显示后台任务、运行状态和日志，并提供可用的取消操作。
- 右侧“运行诊断”常驻检查 Python、14 个工具模块、工作目录写入权限和可选的 Node.js 依赖。
- 诊断面板支持“重新检查”“检查文件”和“复制报告”；出现异常时先选中项目查看处理建议。

## 首次登录和本地配置

真实账号、密码、Cookie、浏览器 profile、登录态和 WPS 本机配置均由 `.gitignore` 忽略，不会上传到 GitHub。WPS 写入功能的随包默认配置单独维护，不含账号、登录态或旧电脑的本地文件路径。

### 广东现货系统账号

打开工具箱，在右侧“任务中心”下方的“清能网站账号”填写账号、密码。默认自动保存，也可点击“保存”；原有默认账号密码会自动填入，支持显示或隐藏密码。

统一账号保存在 `.toolbox/qingneng/config.json`（仅本机、Git 忽略、权限 `0600`）。导出上网电量、风力预测截图、市场表更新、现货价格分析表更新、交易系统信息更新、功率调整收益统计表更新、生成报告、南方分公司电力市场日报、集团每日上传和私有数据上传统一读取此账号。各工具的日期、路径、机构等业务配置仍保存在原来的配置文件中。

修改账号密码后，从下次启动任务开始使用新设置，各工具首次运行会重新登录。正在运行的任务继续使用启动时的设置。每个工具各自维护登录态、锁和浏览器 profile；账号修改不会删除这些文件。

如需调整业务配置，复制示例配置：

```bash
cp "上网电量抓取/config.example.json" "上网电量抓取/config.json"
cp "每日生产经营情况汇报自动生成工具/scripts/config.example.json" \
   "每日生产经营情况汇报自动生成工具/scripts/config.json"
```

编辑生成的 `config.json` 中的业务字段。尚未保存统一账号时，命令行工具仍兼容原有配置中的 `username`、`password`。

下列工具各自保存独立登录态，可以并行运行，互不占用同一个浏览器 profile：

```text
上网电量抓取/auth_state.json
市场表更新/auth_state.json
现货价格更新/auth_state.json
交易系统信息更新/auth_state.json
功率调整收益统计表更新/auth_state.json
集团每日上传/auth_state.json
每日生产经营情况汇报自动生成工具/scripts/auth_state.json
```

使用“导出上网电量”“市场表更新”或“上传集团每日数据”等功能时：

1. 在右侧“清能网站账号”填写并保存账号密码。
2. 打开对应功能页，直接运行任务。
3. 工具自动检测已有登录态，必要时使用保存的账号密码登录，并保存各模块自己的登录态。

自动登录失败时，检查账号密码、网络和网站提示后重新运行任务。不要把某个工具的 `auth_state.json` 或 `.browser-profile/` 复制给另一个工具。

右侧账号区只负责填写和保存统一账号密码，各功能页面不再显示“登录/刷新登录状态”按钮。运行诊断仅列出异常或提醒项目；没有问题时收起明细列表。

```bash

   "电力工具脚本/private-data-uploader-tool/upload.config.json"
```

根据示例填写上传地址、匹配规则和浏览器配置。macOS 上如需显式指定 Chrome：

```text

```

首次执行“预览”或“开始上传”时会自动建立登录态。网络不可达时，日志会提示检查内网、VPN、代理和 `baseUrl`。

### WPS/KDocs 配置

WPS 写入工具会在以下位置保存本机配置、登录 profile 和日志：

```text
wps自动/wps_excel_to_kdocs_config.json
wps自动/wps-browser-profile/
wps自动/logs/
```

软件自带 `wps自动/wps_excel_to_kdocs_config.defaults.json`，包含上网电量、日前电量、实时电量 3 项写入配置及 34 个写入区域。首次使用且没有本机配置时自动载入；已有本机配置（包括自行清空的配置）优先保留，不会被更新覆盖。桌面安装包首次安装会将默认配置初始化到用户目录 `data/wps自动/wps_excel_to_kdocs_config.json`；源码迁移包也携带同一默认配置。

默认配置保留目标表格链接、来源及目标工作表、单元格范围和字段顺序；本地来源文件留空，请在新电脑选择相应表格文件，再登录 WPS 后写入。后续只要 profile 有效，通常无需重复登录。配置仍可在工具界面中导入或导出。调整随包业务配置时维护 `.defaults.json`，日常界面修改继续保存在本机配置中。

macOS 默认使用“Dedicated WPS Chrome (recommended)”模式，通过本机 `127.0.0.1:9222` 与独立 Chrome 会话连接。可在 WPS 工具页点击“Start/open dedicated Chrome”和“Check status”，也可以在 Finder 双击：

```text
wps自动/启动WPS专用Chrome.command
```

专用 Chrome 与日常 Chrome 使用不同 profile。首次启动后在这个窗口登录 WPS/KDocs；保持该窗口运行，再回到工具箱预览或写入。

## 功能使用说明

点击日期输入框内部即可弹出日历，支持按月、按年切换及选择“今天”，也可手动输入或粘贴。月、日允许一位或两位数字，例如 `2026-7-6`、`2026-07-6`、`2026-7-06`、`2026-07-06`；同时接受 `2026/7/6`、`2026.7.6`、`2026年7月6日` 和 `20260706`。输入会统一转换为 `YYYY-MM-DD`，无效日期会提示纠正。界面中的 `D` 表示所填写的基准运行日。

### 1. 导出上网电量

用途：按日期抓取各公司、各机组上网电量并生成 Excel 汇总。

操作步骤：

1. 首次使用先在右侧“清能网站账号”填写并保存账号密码。
2. 在“导出日期”中选择或填写需要导出的业务日期；默认值为昨天。
3. 点击“开始导出”。
4. 在页面日志中确认抓取和文件保存结果。
5. 点击“打开输出目录”查看 Excel。

输出目录：`上网电量抓取/输出/`。

### 2. 市场表更新

用途：按一个基准运行日抓取多类市场数据，写入指定的年度市场 Excel。该功能会修改所选工作簿，运行前请关闭 Excel/WPS，并建议先保留备份。

操作步骤：

1. 首次使用先在右侧“清能网站账号”填写并保存账号密码。
2. 填写“基准运行日期”。
3. 选择市场 Excel；默认路径为桌面日常工作目录中的 `现货统调市场出清、结算数据2026.xlsx`。
4. 确认工作簿包含 `2026年市场情况` 和 `2026年运行方式及成本` 工作表及对应日期行。
5. 关闭正在打开该文件的 Excel/WPS 窗口。
6. 点击“开始更新”，等待完成提示。

当前写入口径：

| 数据 | 来源日期 | 目标工作表和列 |
| --- | --- | --- |
| 市场负荷信息：日前 | D | `2026年市场情况`，`B:U` |
| 日前市场 12 项 | D-1 | `2026年市场情况`，`V:AG` |
| 市场负荷信息：实际 | D-2 | `2026年市场情况`，`AH:BA` |
| 实时市场 4 项 | D-2 | `2026年市场情况`，`BB:BE` |
| 发电侧结算 12 项 | D-6 | `2026年市场情况`，`BF:BQ` |
| 用电侧结算 7 项 | D-6 | `2026年市场情况`，`BR:BX` |
| 单位变动成本对应电价 | D | `2026年运行方式及成本`，`N:X` |
| 在线机组数、预测检修容量 | D | `2026年运行方式及成本`，`AA`、`AE` |
| 燃煤/燃气开机台数 | D | `2026年运行方式及成本`，`AB:AC` |
| 机组运行方式 | 复制 D-1 | `2026年运行方式及成本`，D 行 `B:M` |

如果某一数据源当天不可用，日志会说明该映射被跳过；其他可用映射仍会继续处理。

### 2.1 交易系统信息更新

用途：从“公有数据管理 → 现货运行日报 → 市场负荷信息”抓取数据，接续更新 `交易系统信息收集20260901.xlsx` 的 `Sheet1`。

- 日期口径固定为日前 D、实际 D-3；开始日期留空时自动从工作簿最后一组的下一天接续。
- 日前西电行保留原格式，四个数值留空；实际侧写入西电数据。
- 日前 B 类的最大、最小、平均、总电量分别扣减 D-3 实际西电的对应数值。
- 每类数据依次写入最大、最小、平均和总电量，字段顺序和样式复制最后一组。
- 写入前默认在原目录生成时间戳备份，保存后自动回读日期、字段和数值。

### 2.2 功率调整收益统计表更新

按文件名识别归湖、鮀莲，补齐桌面“日常工作”中两个功率预测调整收益统计表截至 D 日的 C、J、K、L、M、N 六列0–23点数据。非空值（含0与公式）跳过，未发布数据留空；保留模板格式与收益公式，解除文件只读，并默认备份、写后回读。详细字段及单位见 [模块说明](功率调整收益统计表更新/README.md)。

### 3. 广东电价预测

用途：补齐广东现货历史数据总表，并使用滚动训练生成 D+1 日前电价预测。

补齐数据总表：

1. 确认账号配置已完成。
2. 填写“运行日 D”。
3. 点击“补齐数据总表”。
4. 工具检查截至 D 日缺少 96 个十五分钟时点的日期，只补抓空缺数据。
5. 数据持续写入唯一的 `广东电价数据总表.xlsx`。

运行预测：

1. 先确保数据总表已存在并包含足够历史数据。
2. 选择预测输出目录。
3. 设置滚动训练月数，默认最近 3 个自然月，最少 2 个月。
4. 点击“运行 D+1 预测”，固定导出总表最后日期的下一天。

建模会自动排除实际/实时等会造成未来信息泄漏的字段。默认输出：

- `广东电价预测/输出/广东电价数据总表.xlsx`
- `广东电价预测/输出/D+1预测/D+1日前电价.xlsx`
- `广东电价预测/输出/D+1预测/MAE.json`

预测 Excel 包含 D+1 日期、96 个十五分钟时点和日前电价；`MAE.json` 保存模型误差指标。

更新脚本、预测脚本和页面共同读取本模块 `config.json` 的 `masterWorkbook` 与 `predictionOutputDir`。配置中的相对路径统一以 `广东电价预测/` 为基准，支持 `~`；页面修改总表路径后，补齐与预测均使用该路径。“打开预测目录”打开页面当前填写的目录。

初始历史表可放在 `广东电价预测/输入/广东数据初始总表.xlsx`，或通过 `initialWorkbook` 指定；已有总表时优先使用总表。旧数据更新烟测产物已清理，节假日分析资料保留在 `广东电价预测/历史分析/节假日负荷恢复分析/`。

### 4. 电力交易分析

用途：读取一个或多个“出清情况”Excel，批量生成 HTML 分析报告。

操作步骤：

1. 点击“添加文件”选择一个或多个 `.xlsx`；也可以点击“自动匹配D和D-2”。
2. 自动匹配会在 `~/Downloads` 中查找文件名含“出清情况”的 D 和 D-2 文件，并选择每个日期最后修改的一份。
3. 使用“移除选中”或“清空列表”调整文件列表。
4. 选择输出目录，默认是 `~/Downloads`。
5. 点击“开始分析”。

每个输入文件会生成一个 `<原文件名>_分析报告.html`。

### 5. 500kV断面分析

用途：批量清洗日前或实时节点电价，按内置 500kV 拓扑识别价格分化断面，并生成可交互 HTML 拓扑网页。原始 Excel 不会被覆盖。

操作步骤：

1. 点击“添加电价文件”，选择一份或多份节点电价 `.xlsx`。
2. 确认“拓扑名单”为 `500kV断面分析/500kV节点拓扑.md`；只有需要使用另一份已校验拓扑时才更换。
3. 选择结果目录，默认是 `500kV断面分析/result/`。
4. 设置价差阈值，默认 `100` 元/MWh，阈值必须大于或等于 0。
5. 点击“开始分析”，完成后使用“打开结果目录”或“打开最近网页”。

当前判定规则同时要求：

- 相邻节点价格一涨一跌。
- 两端价差严格大于设置阈值。
- 条件连续满足至少 4 个时点。

网页颜色由累计触发时点和最大价差共同决定，颜色越深表示持续时间越长且价差越大。每份输入会生成独立子目录和 `<原文件名>_500kV分析.html`；中间清洗 Excel 和断面明细仅在临时目录使用，完成后自动删除。

也可双击 `500kV断面分析/500kV 断面分析.command` 使用独立窗口。节点位置维护人员可运行 `500kV断面分析/校准500kV节点位置.command`，日常分析无需执行校准。

### 6. 广东运行日报解析上传

操作步骤：

1. 选择运行日报 PDF。
2. 确认自动生成的输出 Excel 路径，必要时更换保存位置。
3. 默认选择“解析并上传”；也可选择“仅解析”或“仅上传”已有结果。
4. 点击“解析并上传”。模块按 PDF 报告日期，分别在“现货交易日报”和“报价容量数据”选择对应日期行、选择文件、执行“全部上传”，并回读网站状态。
5. 完成后可打开输出目录检查本地 Excel；上传失败时本地文件仍保留，可用“仅上传”重试。

工具会从日前申报信息表读取“零价及以下”和“报价 600 以上”汇总值，用于校验和校准图像识别结果。

### 6A. 南方分公司电力市场日报

选择 `d 日收益表`、上一日对比表和 `d-2 收益表`，日期分别对应报告日、报告日前一日和前两日。可填写东莞运行方式修正和实时检修容量。点击“生成日报”后，工具读取清能系统市场数据，并只保存精简加大长页手机预览版 PDF 与打印版 PDF。网站登录复用工具箱“上网电量抓取”的登录实现及配置；首次运行会复制已有登录态，之后日报使用独立的浏览器 profile、登录态和锁文件。

如果网站账号密码尚未配置，请先按“导出上网电量”的登录说明完成配置。日报依赖 `Jinja2` 和 `pypdf`，运行 `./setup_macos.command` 会安装。

### 7. 出清结果汇总上传

用途：共用一个复盘文件夹，选择“仅汇总”“仅上传”或“汇总并上传”。

操作步骤：

1. 选择“复盘文件夹”，可以直接选择混放所有出清 Excel 的大文件夹。优先使用 `~/Desktop/日常工作/复盘`，默认匹配 D+1 日期目录，不存在时选最近修改的目录（排除“模板”）。
2. 选择执行功能；包含汇总时，确认输出文件，默认是复盘目录根目录下的 `<文件夹名>_汇总.xlsx`。
3. 包含上传时，点击“预览上传文件”，核对日志中的原始文件和上传目标。
4. 点击对应的开始按钮；包含上传时核对确认对话框。

点击原有的汇总、上传或预览按钮时，程序会先自动把混放文件移入所选文件夹下的 `东莞、归湖、汕头、海门、海风、鮀莲` 六个单元目录，再执行对应功能。结构参考 `~/Desktop/日常工作/复盘/模板`，不会改动模板，也不创建额外的“已归类”目录或新增操作按钮。

文件名只识别有效日期和“日前/实时”；单元归属只读取工作表名。“谢岗”归东莞，“华归光伏电站”归归湖，“广澳海风场”归海风，“鮀莲光伏电站”归鮀莲。自动识别支持 `.xlsx`；工作表无法识别或涉及多个单元时，列出文件并停止，不用文件名猜测单元。

归类时自动将文件名统一为 `日前交易结果查询(YYYY-MM-DD).xlsx` 或 `实时交易结果查询(YYYY-MM-DD).xlsx`，去掉前面的机组编号等文字。同一单元、同一日期、同一类型有多个文件时，在日期后加 `(2)`、`(3)` 等序号；已在单元目录中的文件也会整理命名。

移动前后校验文件内容，保留日期和格式；同名文件分别保留，不覆盖已有文件。移动中断时尽量恢复原位置，未能恢复的文件路径会写入日志。缺少单元时提示具体名称，已有数据继续汇总和上传；再次运行时不会重复移动已整理好的文件。

已分好的复盘目录继续按原流程使用。“仅汇总”还支持单个场站文件夹，保留原始日前、实时交易结果的字段顺序和显示精度，无需 Node.js；上传功能需要安装 Node.js 依赖。

“汇总并上传”先生成 Excel，成功后再上传原始匹配文件；汇总失败时停止。汇总文件应放在复盘目录根目录或目录之外，避免进入上传匹配范围。上传失败时，已生成的汇总文件保留，日志显示其路径。

上传沿用私有数据上传工具的独立登录态和文件匹配规则，不会自动重试。包含上传的任务开始后不可安全取消；若上传中断，应先在目标系统确认成功情况，再决定是否重新执行。

### 8. 生成报告

数据日期口径：

- 报告日 Excel：报告日 D 的日前电量/价格。

4. 根据需要勾选“抓取网站数据并汇总 Excel”和“生成 Word 报告”，至少选择一项。
5. 点击“开始生成”。两项都勾选时会先抓取，再生成 Word。

生成 Word 时 3 个 Excel 均为必填。输出目录：`每日生产经营情况汇报自动生成工具/输出/`。

### 11. WPS 写入工具

用途：把本地 Excel 或 KDocs 来源区域写入一个或多个目标 KDocs/WPS 表格区域。

基本流程：

1. 新建或选择一个文档配置。
2. 填写目标 KDocs URL。
3. 选择来源类型：本地 Excel 或 KDocs。

5. 为每个区域填写来源工作表、来源起止单元格、目标工作表和目标起止单元格。

10. 点击“Write to WPS”，在页面专用日志中确认写入及保存结果；需要复用配置时使用 Import/Export。

写入前建议先在目标表保留副本。不要同时用多个窗口写入同一个目标区域。

## 后台任务与取消

耗时任务在后台运行，切换功能页不会中断任务。右侧任务中心显示任务状态和日志。

- 数据读取、预览和报告生成等任务在安全时可以取消。
- 上传、覆盖 Excel 和外部写入不会自动重试，部分任务也不可取消。
- 关闭工具箱时，如果仍有任务运行，程序会列出任务并要求确认。
- 工具箱只终止由本次工具箱启动的线程或子进程，不会关闭其他独立运行的程序。

同一个 Excel 正在被 Excel/WPS 打开时，写入工具可能报权限错误。先关闭工作簿，再重新运行。

## 迁移到另一台 Mac

推荐使用 Git 克隆最新版本。如果需要离线迁移，也可以复制整个项目文件夹，但不要依赖旧电脑的 `.venv`：

在当前 Mac 上生成不含登录态、缓存和真实配置的迁移压缩包：

```bash
./package_macos.command
```

压缩包会生成到 `dist/`，并包含当前工作区里尚未提交的源码修改和新文件。

1. 把项目复制到新 Mac。
2. 可以删除复制来的 `.venv`，由新电脑重新创建。
3. 在项目根目录执行隔离属性和执行权限命令。
4. 运行 `./setup_macos.command`。
5. 按“首次登录和本地配置”重新准备配置与登录态。
6. 运行启动 smoke test，再启动图形界面。

本地账号配置可以通过安全方式单独迁移，但浏览器 profile 和登录态可能与旧电脑环境绑定；遇到失效时应在新电脑重新登录。

## 代理和网络

脚本会读取常见代理环境变量。例如本机代理端口为 `7897` 时：

```bash
export HTTPS_PROXY=http://127.0.0.1:7897
export HTTP_PROXY=http://127.0.0.1:7897
```

如果代理端口不同，请按实际设置修改。遇到登录页面打不开、Playwright 超时或上传请求失败时：

1. 先用 Chrome 手动确认目标系统可以访问。
2. 检查 VPN、代理软件和代理端口是否正常。
3. 确认右侧保存的账号密码正确后，重新运行对应任务。
4. 查看页面中最早出现的错误，不要只根据最后一行判断原因。

## 常见问题

### 双击 `.command` 没有反应

在项目根目录执行：

```bash
xattr -dr com.apple.quarantine .
chmod +x setup_macos.command "00_启动/电力工具箱.command" \
  "wps自动/启动WPS专用Chrome.command"
./00_启动/电力工具箱.command
```

终端会保留具体错误信息，便于定位安装或路径问题。

### 提示缺少 Python 模块

重新安装根目录依赖：

```bash
./setup_macos.command
```

确认测试或脚本使用 `.venv/bin/python`，不要混用另一个 Python 环境。

### Playwright 找不到浏览器

```bash
.venv/bin/python -m playwright install chromium
```

### 登录状态失效或页面跳回登录页

确认右侧“清能网站账号”的账号密码正确后，重新运行对应任务。各工具独立检测和刷新自己的登录态。

### Excel 提示权限错误或保存失败

关闭 Excel/WPS 中正在打开的目标文件，确认文件不是只读且目录可写，然后重新运行。市场表更新会直接修改所选文件，建议事先备份。

### 私有数据上传提示找不到 Node.js

安装 Node.js 18 或更新版本，然后执行：

```bash
cd "电力工具脚本/private-data-uploader-tool"
npm install
```

### WPS 提示无法连接 Chrome 或调试端口

先关闭使用 `wps-browser-profile` 的旧专用 Chrome 窗口，再双击：

```text
wps自动/启动WPS专用Chrome.command
```

回到 WPS 工具页点击“Check status”。专用 Chrome 需要保持运行，并使用独立 profile；不要让另一个 Chrome 进程占用 `127.0.0.1:9222`。

### 测试提示 `No module named 'toolbox'`

测试需要从 `电力工具箱` 目录运行：

```bash
cd "电力工具箱"
PYTHONPATH=.. ../.venv/bin/python -m unittest discover -s tests
```
