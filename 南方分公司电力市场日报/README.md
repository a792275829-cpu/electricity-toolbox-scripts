# 南方分公司电力市场日报

工具箱“分析与报告 → 南方分公司电力市场日报”。读取 D、D-1、D-2 三份收益表和清能系统市场数据，生成手机预览版与打印版 PDF。

## 使用

1. 填写“报告日期”，默认明天。
2. 选择三个输入，全部必选：
   - `d 日收益表`：报告日 D 的收益表；
   - `上一日对比表（必选）`：D-1 的对比表；
   - `d-2 收益表`：D-2 的收益表。
3. 需要补录市场数据时点“手动填写数据”，按报告日期填写；改日期会清空已补录内容。
4. 点击“生成日报”，完成后弹窗给出输出目录；也可点“打开输出目录”。

市场数据从清能系统读取，复用工具箱的登录实现和统一账号。若账号未配置，先按[导出上网电量](../上网电量抓取/README.md)的登录说明完成配置。

## 命令行

```bash
.venv/bin/python 南方分公司电力市场日报/run_market_report.py 2026-11-03 \
  --day-report d.xlsx --previous-report d-1.xlsx --d2-report d-2.xlsx
```

可选 `--dongguan-operation`、`--realtime-maintenance` 补充材料，`--manual-market` 传入按日期绑定的补值 JSON（工具箱页面自动生成）。

## 输出

`南方分公司电力市场日报/输出/<报告日期>/` 下两份 PDF：手机预览版（长页）和打印版。

## 依赖

`Jinja2`、`pypdf`，由 `./setup_macos.command` 安装。

## 登录态与测试

首次运行会复制“上网电量抓取”已有登录态，之后本模块使用独立的 `.state/auth_state.json`、锁和浏览器 profile，与其它工具互不影响。测试随 `tooling/run_tests.py --suite report` 运行。
