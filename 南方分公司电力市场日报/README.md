# 南方分公司电力市场日报

工具箱“分析与报告 → 南方分公司电力市场日报”。读取 D、D-1、D-2 三份收益表和清能系统市场数据，生成手机预览版与打印版 PDF。

## 使用

1. 选择三个输入，全部必选：
   - `D 日收益表`：报告日 D 的收益表，报告日期按该表的日期自动识别；
   - `D-1 日收益表`：D-1 的对比表；
   - `D-2 日收益表`：D-2 的收益表。
2. 报告日期不需要填写，界面按 `D 日收益表` 自动显示；更换 `D 日收益表` 会重新识别，日期变化时清空已补录内容。
3. 需要补录市场数据时点“手动填写数据”，按自动识别的报告日期填写。日前、实时各有 9 项指标，每项填写当前值和对比值，共 36 个输入；增减自动计算。日前为 D 对比 D-1 日前，实时为 D-2 对比 D-2 日前。网站数据优先，手填仅补缺，留空不补录。
   - “清空本页”只清当前页；切换页签保留另一页草稿，“取消”不修改已保存补录。
   - “保存并返回”会校验全部输入；煤机／气机台数须为非负整数，价格允许负数，其余指标须为非负数。错误会显示在弹窗中，修改后可直接重新保存；保存后重新打开可继续编辑。
   - WebView 字段加载失败时可点“重试加载”；未选择 D 日收益表时先选表，不手工推断报告日期。
4. 点击“生成日报”，完成后弹窗给出输出目录；也可点“打开输出目录”。

收益表支持“新快报”、符合日报结构的“新”及带版本号的“快报”工作表。模板识别按日期、公司汇总行和日前电量／电价表头判断，不要求日前、实时简析文字非空；旧版文字模板仍兼容。各消费步骤继续校验其所需数据，报告日及 D、D-1、D-2 的日期校验口径不变。

“新”表兼容海门四机／六机模板：日前出清总览随来源保留 #5、#6 两行、合并分组、数值格式及“/”占位；日前曲线、实时汇总日期和量价指标按分区日期、汇总标签与表头定位，新增机组行不会错位读取东莞、清远或新能源。实时机组明细按“海门”表实际提供的独立小时块纳入 #5、#6，出现相应块时继续检查表头和完整 24 小时，只有汇总占位时不补造小时数据。

策略中的“各机组日前收益”按来源表的日前偏差边际贡献核对，支持海门四机／六机及新增机组 `/` 占位；只有金额列表与从 #1 起的机组顺序唯一对应时才回填，缺项、重复、未知机组或错误值均保留原文，不将占位当成 0。旧文字模板兼容“日前简析”和“日前市场简析”，分时附表兼容 Excel 时间值与 `08:00:00` 文本。海门 #5、#6 出现标题而缺少有效小时块时停止并指出缺块，完整小时块继续校验 24 小时。

市场数据从清能系统读取，复用工具箱的登录实现和统一账号。若账号未配置，先按[导出上网电量](../上网电量抓取/README.md)的登录说明完成配置。

## 命令行

```bash
.venv/bin/python 南方分公司电力市场日报/run_market_report.py 2026-11-03 \
  --day-report d.xlsx --previous-report d-1.xlsx --d2-report d-2.xlsx
```

可选 `--dongguan-operation`、`--realtime-maintenance` 补充材料，`--manual-market` 传入按日期绑定的补值 JSON（工具箱页面自动生成）。命令行仍显式传入报告日期，必须与 D 收益表日期一致，否则直接报错退出。

## 输出

`南方分公司电力市场日报/输出/<报告日期>/` 下两份 PDF：手机预览版（长页）和打印版。

文件名分别为 `<报告日期>_南方分公司电力市场日报.pdf` 和 `<报告日期>_南方分公司电力市场日报_打印版.pdf`，例如 `2026-11-09_南方分公司电力市场日报.pdf`。

## 依赖

`Jinja2`、`pypdf`，由 `./setup_macos.command` 安装。

## 登录态与测试

首次运行会复制“上网电量抓取”已有登录态，之后本模块使用独立的 `.state/auth_state.json`、锁和浏览器 profile，与其它工具互不影响。测试随 `tooling/run_tests.py --suite report` 运行。
