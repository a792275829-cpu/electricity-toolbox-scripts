# 早报生成

工具箱“分析与报告 → 早报生成”。抓取每日网站数据并基于 3 个 Excel 数据源生成生产经营情况 Word 报告；也可以只用现有 Excel 生成报告。

## 数据日期口径

- 前一日 Excel：报告日 D-1 的上网电量、日前均价，以及 D-1 的机组启停状态。
- 报告日 Excel：报告日 D 的日前电量／价格，以及 D 的机组启停状态。
- 前两日 Excel：报告日 D-2 的日清数据，用于“四、日清分情况”的表1 与“3.现货偏差分析”。

生成 Word 时三份 Excel 都是必填。支持海门四机和含 #5、#6 机组的六机两种模板：“快报”“快报（日前）”按厂名与机组标签定位，不依赖新增行后的固定行号。

## 全省市场均价

生成 Word 时，报告日 D 的全省日前出清均价及环比优先读 D 日工作簿“快报（日前）”A 列“日前简析”；日清分 D-2 的全省实时均价优先读 D-2 工作簿“快报”A 列“实时简析”。扫描 A1:A80，兼容 A41/A42 行号变化及工作表名的空格、全角括号。元/兆瓦时与厘/千瓦时数值等价，不采用各厂加权电价代替全省市场均价。

工作簿的“基础信息”!A2 必须与对应日期一致，且简析须含有效均价，否则提示并保留网站价格。简析提供环比时按原文方向取正负，比较日价格由均价减环比还原；没有环比时比较价与差值留空，不与网站价格混算。D-2 的日前均价及其他价格仍用网站值。具体文件、工作表、单元格和原网站值记录在 Word 审计 `marketPriceSources` 中。简析可能沿用历史文字，使用前需核对其填报日期与内容。

同时勾选“抓取网站数据并汇总 Excel”和“生成 Word 报告”时，两份产物共用一次网站抓取，均价口径一致；命令行对应 `generate_red_marked_report.py ... --save-data-summary`。只抓取网站数据时仍由 `fetch_daily_data.py` 导出网站值。未来日期的实时均价尚未出数可留空，不视为任务失败；容量接口失败会显示实际日期和接口错误码。

报告日的清远计划电量取“基础信息”表“清远上网电量（MWh）”区块中，“计划发电量”表头下的“合计”行 AA、AC 两列之和，再除以 10，以万千瓦时计入清远及分公司总电量。四机模板通常为 AA64+AC64，六机模板通常为 AA66+AC66；实际采用的地址和值记入审计 `qingyuanDayAheadSource`。合计行或公式缓存缺失时提示，不用某个小时的计划值代替合计。

## 上网电量取数

“1.近两日完成情况”第一句读 D-1 出清情况工作簿的“快报”表：

| 分项 | 单元格 |
| --- | --- |
| 汕头 / 海门 / 东莞 | `J8` / `J13` / `J19` |
| 清远 | `J7 － (J8+J13+J19)`，避开清远的套机组行 |
| 海上风电 / 光伏 | `K32` / `K33+K34`（新能源区“上网电量”列） |
| 总数 | `J7 ＋ (K32+K33+K34)`，与分项相加一致 |

日前均价与各厂电价取同一份 D-1 工作簿“快报（日前）”表，与上网电量分别更新。D-1 的上网电量全为 0（尚未出数）或读取失败时，前半段电量保留模板原文与格式（包括日期、数字和红字）供人工填写，不替换为“待补”；只将“分公司日前均价”起的后半句更新为当前来源值并显式设为黑色。电量有数时整段正常更新为黑色。审计文件 `onlineEnergyError` 记录电量未更新的原因。

“日前出清电量”按**所有单元相加**，不用“快报（日前）”F7 的分公司小计（F7 只含火电三厂，是旧模板的错误口径）：

总数 ＝ 火电三厂（火电区“分公司”行 F 列）＋ 新能源（汕头海风、鮀莲、归湖各行 G 列）＋ 清远计划电量。

以 11 月 4 日为例：6034.81（火电）＋524.01（新能源）＋230（清远）＝6788.82，报告写 **6789 万千瓦时**，与分项“汕头1636＋海门3557＋东莞841＋海上风电452＋光伏72＋清远230”一致。

## 机组启停取数

两日机组启停分别读 D-1、D 两份出清情况工作簿的“基础信息”表“机组状态”区块（表头含“机组状态”的连续区段），按厂名归组、按机组号/套号聚合：

| 厂 | 机组标识 | 状态用词 | 分隔与顺序 |
| --- | --- | --- | --- |
| 汕头 / 海门 | `#1`、`#2`… | 运行、备用（备用/停备/停机统一写「备用」；「应急备用」保留原词）、供热、检修 | `；` 分句，句内 `、` 连接，按运行→备用→供热→检修 |
| 东莞 | `#1,2`＝一套、`#3,4`＝二套、`#5,6`＝三套、`#7,8`＝四套 | 运行→调峰，备用、供热、检修同前 | `，` 分句，**按套号顺序逐套列出**（一套→四套）；状态取自 C 列（如「供热／运行／检修／备用」→「一套机组供热，二套机组调峰，三套机组检修，四套机组备用」）。“约束情况”行的「运行日运行方式」常与 C 列不一致，**不采用** |
| 清远 | 同东莞套号规则 | 运行、备用、供热、检修 | `；` 分句，按套号顺序 |

报告日（第二日）与 D-1 拼出的文字完全一致时，写“与前一日运行方式一致。”。机组状态区块缺失或缺少某厂数据时，保留模板原文并在审计文件 `unitStatusError` 中记录。

海门 #5、#6 机组按“基础信息”实际记录加入；“调试”等其他状态保留原词，排在上述状态之后。旧模板没有这两台机组时不补造记录。

## 日清分表与现货偏差分析取数

两份内容都读 D-2 日出清情况工作簿，按标签定位行、按固定列取数，不写死行号。

表1（24 列 × 15 行）取自“快报”表：

| 表1 行 | 快报定位 | 说明 |
| --- | --- | --- |
| 分公司火电 | 火电区“分公司”行 | 收益列按各厂合计，其余取分公司行 |
| 汕头 / #1 / #2#3 | “汕头”合计及其 #1、#2、#3 机组行 | #2#3 电量相加、电价按电量加权 |
| 海门 / 东莞 / 清远 | 各厂“合计”行 | 四机模板通常为 13 / 19 / 25，六机模板为 13 / 21 / 27；清远无日前、实时、实际上网数据，填“/” |
| 分公司新能源 / 海风 / 鮀莲 / 归湖 | 新能源区对应标签 | 四机模板通常为 31～34，六机模板为 33～36；含机制电量与差价收益 |

- “现货偏差收益”：汕头、东莞取快报 AA 列（现货偏差合计边际贡献），海门取 R+U+X（日前偏差＋实时偏差＋实际上网偏差三项边际贡献），分公司＝三厂之和（不含清远）。
- “总电费”：各厂 M 列之和；“电能量均价”＝(总电费－容量电费)／上网电量×1000，单位厘/千瓦时。
- 收益合计必须具备中长期收益和现货收益；缺失、Excel 错误或非有限数显示 `/`。清远现货收益列按口径显示 `/`，收益合计只取中长期收益。
- 汕头 #2#3 的加权均价要求所有电量和电价有效，不跳过缺失项；加权与综合均价的分母绝对值不超过 `max(1e-9, 各项电量绝对值之和×1e-12)` 时显示 `/`，避免正负电量抵消尾差产生异常大数。
- 电能量均价要求总电费、容量电费（新能源为机制收益）和上网电量有效；上网电量绝对值不超过 `1e-9` 时显示 `/`。清远使用同一计算规则，综合均价读取原值，缺失或错误显示 `/`，有效零值保留 `0`。
- 单元格按 0 位小数显示，负值四舍五入到 0 时保留 `-0`，与 Excel 显示一致。

现货偏差分析取“分公司”表“分公司火电”行：实时出清电量 G、偏差电量 K、实时均价 H、日前均价 F、实际上网偏差 M、浮盈 N；平均运行负荷率＝G／(有效容量 B×24)；最低／最高节点电价按汕头、海门、东莞三张厂表“实时最低价/实时最高价”跨厂取极值。输出为“日前-实时：”与“实际-实时：”两段各一句。

节点电价取厂表里“实时最低价”“实时最高价”这两行（通常在第 14、15 行，第 12、13 行是日前最低价/日前最高价）。这与工作簿 `分公司!B10` 实时段的引用一致：`MIN(汕头!AF14:AH14, 海门!AL14:AO14, 东莞!AL14:AM14)`、`MAX(汕头!AF15:AH15, 海门!AL15:AO15, 东莞!AL15:AM15)`，因此 B10 可以直接当核对基准。以 2026-11-01 为例，实时最低 -50、实时最高 765.49（汕头 #1 的实时最高价），日前最高则是 942.62，两者不要混。

取数失败时保留模板原值并在审计文件 `dailyClearingError` 中记录，不中断报告生成。

若“分公司火电”行的实时电量、偏差、实际偏差、收益**全为 0**，判定为实时尚未出清（通常是误把报告日当天的工作簿当成 D-2）：现货偏差分析保留模板原文、标题保持红字提示人工补数，审计文件记 `spotDeviationSkipped`，表1 仍照常填充。

## 生成前校验与人工段落

三份工作簿的“基础信息”A2 是运行日，生成时会与日期口径逐一核对：前一日工作簿应为 D-1、报告日工作簿应为 D、前两日工作簿应为 D-2。不一致时只打印提示并写入审计文件 `workbookDateWarnings`，**不中断生成**——主要防“前后两天文件选反”和“拿到当天尚未出数的文件”这两种不会报错只会出错数的情况。

自动定位出清工作簿按文件名中的完整点分日期匹配（兼容 `2026.11.1` 与 `2026.11.01`），同日有多份时取最近修改的文件，`11.1` 不匹配 `11.10`。自动定位的 D 日工作簿先参加 A2 运行日核对，再统一用于日前数据、机组启停与三厂策略取数。

“三、现货交易策略”首段由接口数据生成，汕头／海门／东莞三厂策略取自报告日工作簿“快报（日前）”A39 的日前简析（按厂名逐行切分，行首序号“2”“3.”等会被去掉）。工作簿路径**不必手动传**：未指定时按报告日到下载目录自动定位（与日前电量、机组启停等取数一致），实际用到的文件写入审计 `plantStrategiesSource`；工作表匹配时忽略空格，兼容“快报  (日前)”。A39 行号漂移时会在 A1:A80 内按“日前简析”字样回退查找。A39 里若出现“粤东区域：500kV线路……”这类区域线路信息，**不写入报告**：模板里带的那段会在生成时删除，模板文件本身也已去掉。A39 缺少某个厂时该段保留模板原文，并在审计 `plantStrategiesMissing` 与 `manualSections` 中列出；文件、工作表或日前简析本身缺失时也会打印具体原因，不再笼统报“未找到”。

“五、短期市场预测”首段天气由接口更新，段内“预计统调最高负荷……”和后面那段负荷、均价区间仍是手写；这部分会写入审计 `manualSections`，生成时控制台打印“以下小节共 N 段沿用上一份报告，需人工核对”。

“2.实时市场”的 A 类电源（编码 2）、地方电源（编码 3）增减按 D-2 同一运行日的实际平均出力减日前平均出力判断，使用 96 点口径；不使用前一日实际出力作为这两项的基准。审计数据 `marketAnalysisData.loadInfo.byType` 的 `actualVsDayAhead` 保留双方摘要及相同日期，缺少任一平均值时标记“待补充”。统调负荷、B 类空间的实际极值和其他段落的比较口径保持各自现有定义。

日清分表里的负值（电量、电价、收益）写红色，`0`、`-0`、`/` 不标红；同一节的“1.日前市场”“2.实时市场”段落里的负数也标红，`0-1点`、`7-23点`、日期这类写法不会被误标。**“3.现货偏差分析”的两段正文不标红**（“最低节点电价-50元/MWh”“上网偏差电量为-111万千瓦时”保持黑色）。

## 分页与表格尺寸

“四、日清分情况”与“下表为未来五天海风功率预测：”两处设了段前分页，保证各自的标题与表格落在同一页、不被切断。表1 的标题（“表1  11月4日分公司日清分情况”）紧跟小节标题，不单独分页。

海风预测表 26 行原按 12pt、约 16cm 高，填完后统一压到 **10pt、行高 0.5cm、段距 0**，并按版心高度反算行高上限。关键是模板节里有 `<w:docGrid w:type="lines" w:linePitch="312"/>`：Word 默认把表格段落「对齐到网格」，只改字号和行高时每行仍被吸到约 31pt（1.1cm），26 行会跨到第 7 页。所以 `compact_forecast_table` 还会逐段写 `<w:snapToGrid w:val="0"/>`、把段落标记字号同步到 10pt、将单元格上下边距设为 0，并给每行加 `cantSplit`。Word 实测：标题和第 1～26 行全在同一页（第 6 页，行 1 纵坐标 100pt、行 26 约 563pt，版心底约 770pt），全文由 7 页降为 6 页。需要更紧凑时改 `FORECAST_TABLE_FONT_SIZE` 与 `FORECAST_TABLE_ROW_HEIGHT`。

## 红字与措辞

- 模板里“三、现货交易策略”“3.现货偏差分析”两个小标题原为红字。两段均已改为自动生成：现货交易策略按接口数据生成，始终取消标红；现货偏差分析在 D-2 取数成功时取消标红，取数失败则保留红字，提示需人工补数。
- 所有环比措辞按展示精度取整：结果为 0 时统一写“持平”，不出现“环比上升0万千瓦”“环比减少0台”“环比上升0元/兆瓦时”。

负荷信息按清能网站当前编码取数，选择日 D、对比日 D-1，保持以下顺序：

| 指标 | loadType |
| --- | --- |
| 统调负荷 | 1 |
| B类竞价空间 | 6 |
| 西电东送电力 | 4 |
| A类电源出力 | 2 |
| 地方电源出力 | 3 |
| 发电总出力 | 18 |
| 粤港联络线 | 5 |

Word 的运行策略及 D-2 日清分市场分析中，“地方电源出力”均取编码 3。缺少已配置指标时停止并列出可用编码，不以其他指标或零值替代。

## 使用

1. 填写“报告日期”，默认今天。
2. 点击“按日期自动匹配 Excel”，从 `~/Downloads` 按文件名含“出清情况”匹配 D-1、D、D-2 三份；也可以手动逐一选择。
3. 需要指定格式时选择 Word 模板，留空使用脚本默认模板。
4. 勾选“抓取网站数据并汇总 Excel”和／或“生成 Word 报告”，至少选一项。
5. 点击“开始生成”。两项都勾选时抓取一次，依次保存汇总 Excel 与 Word。

输出目录：`每日生产经营情况汇报自动生成工具/输出/`。
