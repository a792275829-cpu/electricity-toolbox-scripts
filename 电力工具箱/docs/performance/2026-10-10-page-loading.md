# 工具箱页面首次加载检查（2026-10-10）

检查范围：全部 14 个导航模块，关注点击模块后页面首次显示。

发现：除已修复的风力预测页外，其余 13 个模块通过 `toolbox.pages` 导入整个页面集合；电量汇总页面依赖的 `review_classification` 随即导入 openpyxl 和 NumPy。市场表映射说明还指定了 Windows 字体，macOS 首次创建该文本框额外耗时约 40 毫秒。

修复：已有独立页面文件的 7 个模块直接使用各自页面入口；openpyxl 延迟至 `identify_station()` 实际读取工作簿时导入；市场表说明使用 `TkTextFont`。保留公共页面导入兼容入口与现有 WPS 后台导入及预热机制。

测量方法：macOS、根目录 `.venv`，每个模块使用独立 Python 进程；创建 `ToolboxApp` 并执行 `update_idletasks()` 后计时，调用 `show_page(模块名)` 再执行 `update_idletasks()`，记录首次显示时间。为避免预热掩盖首次导入成本，计时前不运行事件循环。以下为同机单次样本，实际耗时会随系统负载与文件缓存变化。
