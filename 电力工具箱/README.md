# 电力工具箱（Tk 界面层）

统一 GUI 入口，负责导航、页面、任务中心、账号区、运行诊断，并把用户操作转成各工具的命令行调用。业务实现不在本目录，见各自工具目录与 `toolbox_shared/`。

启动：`00_启动/电力工具箱.command`（源码）或已安装的 `电力工具箱.app`。调试用 `00_启动/源码调试版.command`，涉及 Tauri 生命周期时用 `00_启动/Tauri开发版.command`。

## 使用界面

左侧按“数据采集”“分析与报告”“上传与写入”分组，启动默认打开“导出上网电量”。工具页面首次打开时加载，切换页面保留当前状态。

右侧任务中心显示后台任务、状态和日志；运行诊断可重新检查环境、检查文件并复制报告，有异常时查看对应处理建议。

日期支持日历选择、手动输入和粘贴，`2026-7-6`、`2026/7/6`、`2026.7.6`、`2026年7月6日`、`20260706` 会统一为 `YYYY-MM-DD`。界面的 `D` 表示填写的基准运行日，各工具的取数日期与写入口径见对应模块文档。

## 账号与登录

打开工具箱，在右侧“任务中心”下方的“清能网站账号”填写账号、密码。账号密码填写完整后，停止输入 1 秒自动保存到本机；离开账号输入区、按回车、启动需要账号的任务或关闭窗口时会立即保存完整输入。字段未填完整时保留原账号，不覆盖为空。账号区不显示保存按钮，状态与“显示密码”同排靠右显示。密码默认隐藏，可主动勾选“显示密码”。

应用启动后在后台验证已保存账号，主界面可正常操作。状态同时使用文字、图标和颜色提示：

| 状态 | 提示颜色与操作 |
| --- | --- |
| 待填写／待验证、正在验证账号 | 灰色 |
| ✓ 账号有效 | 绿色 |
| ✗ 账号或密码错误、连接失败、登录服务暂不可用 | 红色；点击“重试验证”重新检查已保存账号 |
| ⚠ 需要人工验证 | 橙色；在需要登录的功能页点击账号区“打开登录窗口” |

自动保存与联网验证分开执行：账号发生变化后等待 500 毫秒后台验证一次；仍在账号或密码框内编辑时暂不联网，离开输入区或按回车后再验证。相同内容不重复写入或验证。启动检查等待界面显示后执行一次，不做定时轮询。账号错误、网络失败或验证码要求均停止自动验证，需手动重试或修改账号；同一账号的手动重试至少间隔 10 秒。

验证期间可点击“停止验证”；编辑账号、关闭窗口或进入应用更新流程也会停止等待并作废旧结果。每轮界面等待最多 20 秒，单个网络请求最多 5 秒；停止后不发出后续请求，已经发出的请求按短超时收尾。取消更新不自动恢复验证，可手动重试。任意时刻只允许一个验证工作线程，新的账号检查会等待旧请求结束。

后台验证不写账号配置或工具登录态。“账号有效”表示上次账号核验通过，各工具在任务执行时建立或复用自己的独立会话；任务启动时提交账号草稿由任务自行检查登录，不额外启动一次账号验证。

统一账号保存在 `.toolbox/qingneng/config.json`（仅本机、Git 忽略、权限 `0600`）。导出上网电量、风力预测截图、市场表更新、现货价格分析表更新、交易系统信息更新、功率调整收益统计表更新、早报生成、南方分公司电力市场日报、上传集团每日数据和私有数据上传统一读取此账号。各工具的日期、路径、机构等业务配置仍保存在原来的配置文件中。

修改账号密码后，从下次启动任务开始使用新设置，各工具首次运行会重新登录。正在运行的任务继续使用启动时的设置。每个工具各自维护登录态、锁和浏览器 profile；账号修改不会删除这些文件。

业务配置与账号分开保存：工具自己的 `config.json` 用于日期、路径、机构等选项，字段见各模块 README 和 `config.example.json`。命令行调试且尚未保存统一账号时，可在工具配置补充账号；缺少账号时兼容读取 `上网电量抓取/config.json`。本地业务选项不会覆盖共享账号。

自动登录失败时，先检查账号密码、网络和网站提示，再重新运行任务。不要把某个工具的 `auth_state.json` 或 `.browser-profile/` 复制给另一个工具。

## 后台任务与取消

耗时任务在后台运行，切换页面不会中断。读取、预览和报告生成等任务在安全时可取消；上传、覆盖 Excel 和外部写入不会自动重试，部分任务不可取消。关闭工具箱时会列出仍在运行的任务并要求确认，只终止本次工具箱启动的线程或子进程。

## 代码地图

```text
电力工具箱/
├── toolbox/
│   ├── catalog.py          # 16 个工具的 tool_id、名称、分组、页面类
│   ├── pages.py            # 大部分工具页面（ToolPage 子类）
│   ├── *_page.py           # 独立页面的工具（现货价格、交易系统、风力、500kV、日报、市场日报、功率收益、汇总上传、私有数据批量上传）
│   ├── commands.py         # 页面参数 → 子进程命令行
│   ├── runtime.py          # ToolPaths（各工具脚本与输出路径）、load_module
│   ├── tasks/              # 进程执行、取消、进程组回收、任务事件
│   ├── workflows.py        # 组合流程（如抓取 → 生成报告）
│   ├── diagnostics.py      # 运行诊断检查项
│   ├── page_contracts.py   # 桌面服务用的字段契约
│   ├── service.py          # Tauri 业务服务
│   ├── ui/                 # 导航、任务中心、账号区、诊断面板、主题、视口
│   └── widgets.py          # ToolPage 等公共控件
└── tests/                  # 页面、导航、任务、业务契约测试
```

`toolbox_shared/` 是与 Tk 无关的公共实现（登录、凭据、存储路径、市场契约、WPS、交易报表等），由各工具和界面共同导入；根目录不再放实现模块。

## 新增一个工具

1. 在工具目录实现业务脚本，提供 `--login`、日期等命令行参数，输出写到自己的目录。
2. 在 `toolbox/catalog.py` 的 `default_catalog()` 注册 `ToolDescriptor`（`tool_id`、侧栏名称、分组、页面类）。
3. 在 `toolbox/pages.py` 或独立 `*_page.py` 写 `ToolPage` 子类：`tool_id` 与目录一致，声明标题和按钮。
4. 在 `toolbox/commands.py` 里把页面参数拼成命令行，页面只负责收集参数与展示日志。
5. 需要桌面版字段契约时同步 `page_contracts.py` 与 `service_catalog.py`。
6. 补测试：页面创建与参数、命令拼装、失败提示；确认 `test_catalog_loading.py` 会遍历到新页面。
7. 更新根 README 的工具索引与模块 README。

## 约定

- 工具页面只展示标题、操作控件和必要口径，不放重复的功能介绍、日期点击提示或流程说明；日期来源、覆盖规则、单位、风险与运行状态保留。
- 页面不直接执行业务，统一走 `run_process`／任务引擎；取消只能作用于本次启动的进程组。
- 各模块共用日志组件（含 WPS 写入工具）：运行结果与耗时只在日志正文记录，标题栏保留“运行日志”、复制错误和展开按钮。
- 页面不得跨工具共用登录态或浏览器 profile；账号读写统一走 `toolbox_shared.credentials`。
- 账号读写与核验规则见本文的[账号与登录](#账号与登录)。
- 主线程不导入 openpyxl、NumPy、pandas、Playwright；这些只能在后台任务或子进程里加载。
- 后台动态加载工具时保留 `.venv` 依赖的模块身份，源码调试版的复制解释器同样适用。加载器修复后需重启源码调试版，清除旧进程中的模块缓存。
- 日期输入统一用 `DateInput`，日期范围用 `DateRangeInput`（左右双月历、两步选起止、可切换翻月联动），解析用 `toolbox_shared.dates`。
