# 功率调整收益统计表更新

工具箱“数据采集 → 功率调整收益统计表更新”。按所选日期写入归湖、鮀莲两个功率预测调整收益统计表（默认覆盖已有数值，可改为只补空白），或按日期覆盖海风收益表。

## 使用

1. 页面列出三个工作簿，默认都位于 `~/Desktop/日常工作/`：
   - `功率预测调整收益统计-归湖.xlsx`
   - `功率预测调整收益统计-鮀莲(2)(2).xlsx`
   - `海风博弈收益统计-新.xlsx`
2. 勾选要更新的工作簿，默认不勾选；至少选一个。
3. 填写“日期范围”，结束日期为 D；开始日期可留空（归湖、鮀莲从模板内最早匹配日期起检查全部空白），海风必须明确填写开始日期。点日期框弹出左右双月历，先点开始日期、再点结束日期（两张月历都可点，同月范围也能连续选完），可取消翻月联动独立翻页。
4. 按需调整“覆盖非空单元格”（界面默认勾选：归湖、鮀莲也覆盖已有数值，公式单元格仍保留）和“写入前生成时间戳备份”（界面默认不勾选；命令行默认生成）。
5. 点击开始，等待抓取、写入和回读结果。

## 归湖、鮀莲写入口径

文件名必须包含且仅包含 `归湖`、`鮀莲`、`海风` 中的一个名称。归湖匹配华能（潮州潮安）新能源有限责任公司及华归／归湖场站；鮀莲匹配华能（汕头金平）新能源有限责任公司及鮀莲场站。

| 目标列 | 来源 | 单位处理 |
| --- | --- | --- |
| C 原始功率 | 新能源现货基础信息报送 → 生产运行信息 `forecastPower24` | 直接使用 24 点 MW |
| J 申报功率 | 同页 `stPredictPowerList24` | 直接使用 24 点 MW；未保存时读取 `rawShortTermPower24` |
| K 日前电量 | 新能源现货交易结果 → 出清结果，`dataType=1`，`electricity` | 万kWh × 10 → 模板 MWh |
| L 日前电价 | 同页 `dataType=1`，`acPrice` | 直接使用，与模板价格单位相同 |
| M 上网电量 | 上网电量导出使用的新能源接口 `onlineEle` | 直接使用，与原模板一致 |
| N 实时电价 | 出清结果 `dataType=2`，`acPrice` | 直接使用 |

六列都按请求运行日期写回同日，没有 D-1／D-2 偏移；按 A 列日期和 B 列 0—23 点匹配到相应月份工作表。日期公式 `=A上一日期行+1` 在缓存缺失时仍可解析，跨入下月的占位块跳过。

## 海风收益表

海风工作簿按日期覆盖以下五列，其他列和日期保持原样；公司匹配华能广东汕头海上风电有限责任公司，场站匹配广澳海风场。

| 海风目标列 | 来源 |
| --- | --- |
| C 原始功率 | 广澳海风场、对应运行日的 `forecastPower24`，24 点直接使用 |
| R 申报功率 | 同页 `stPredictPowerList24`，24 点直接使用 |
| N 上网电量 | 复用上网电量导出的海风 `onlineEle`，与导出 Excel 数值一致，不缩放 |
| M 日前电价 | 出清结果 `dataType=1` 的 `acPrice`，24 点直接使用 |
| O 实时电价 | 出清结果 `dataType=2` 的 `acPrice`，24 点直接使用 |

支持 `10月份` 和 `10月` 等月份页，按 A 列日期、B 列小时定位，无日期偏移。缺失或未完整发布的字段保留原值（含公式），日志标明未更新；覆盖共享公式主单元格前先展开同组引用，避免实时字段出现失效引用。

## 校验与提交

- 抓取前检查日期覆盖：从开始日期到截止日期，每天都必须存在完整的 0—23 点块。缺少日期、月份工作表或中间整日块时列出缺失日期并停止，不会把部分日期更新当作全部完成。原模板缺的日期块、合并和收益公式需要先补齐，本工具不推断。
- 逐单元格跳过非空值（包括 0 和公式）。接口未发布或含空点的字段保留空白并记录待补；长度非 24、日期／场站重复或数值非法时停止写入。
- 只更新空白输入单元格，保留公式、格式、图表和其他 XLSX 部件，并设置 Excel/WPS 下次打开时重新计算。
- 默认自动备份，统一提交后逐格回读数值和数字格式；提交或回读异常会回滚本次替换。抓取期间原文件被修改则停止提交。运行时会解除文件的用户只读权限和 Finder 锁定。

## 命令行

```bash
.venv/bin/python 功率调整收益统计表更新/update_power_benefit.py --end-date 2026-11-02
.venv/bin/python 功率调整收益统计表更新/update_power_benefit.py \
  --workbook "$HOME/Desktop/日常工作/海风博弈收益统计-新.xlsx" \
  --start-date 2026-10-16 --end-date 2026-10-21
```

`--workbook` 可重复传入；不传时按归湖、鮀莲默认路径处理。`--no-backup` 关闭时间戳备份，`--headed` 显示浏览器，`--login` 单独登录。
