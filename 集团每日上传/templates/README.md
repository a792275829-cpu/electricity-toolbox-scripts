# 内置省内数据模板

`省内数据模板.xlsx` 来自已有省内样例，保留“省内数据”工作表、A:K 字段顺序、数字格式及 C2:K2 默认内容；清空历史日期 A2 和开机台数 B2。这两个单元格在上传前按能销文件日期及现有网页接口填入。

选择顺序仍为手动指定文件、能销同目录最近日期的省内文件、内置模板。内置模板从源码资源目录读取，不迁入用户数据目录，也不会写入生成结果。输出使用能销文件日期，保存至能销文件夹中的 `广东-省内数据-YYYYMMDD.xlsx`。

保持既有规则：C2 为公式时替换容量项后计算，为数值时保留该值。本模板 C2 为原样例数值，未推测或重建容量公式；D2:K2 继续保留模板内容，包括比例字段的字符串值和空值。自定义这些内容时可显式选择自己的省内文件。

模板随源码和 macOS 桌面资源发布；打包前会检查其存在。用户工作簿、生成文件及登录态仍留在本地。
