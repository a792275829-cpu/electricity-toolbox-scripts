# 符号结构实验 v11

状态：2026-11-07普通研发任务实验快照。操作以[模块README](../README.md)为准。模型、底图、词库、评分或符号结构变化后须重新验证；以下会话目视对应不是独立人工电压／像素真值。

## 本轮分析及实现

桃源图符由两个分离半圆瓣组成，单圆检测分别拟合到一瓣或邻站。新增候选要求两瓣为黑边封闭的着色内部，面积相近、颜色一致、半椭圆轴比及方向一致、轮廓凸性充分且质心偏移相反；取二者对称中点，不硬编码站名或生产坐标，不把此锚点计入圆拟合精度。此检测只补充220kV候选；不能由颜色或符号形状判断电压。

妈湾厂附近最高分圆点实际邻近腾飞。新增正弦发电机结构证据：完整黑环内部只有一个无孔、居中、宽扁且两侧上下起伏相反的黑色笔画；排除直线、空圆和电池框。厂名只有在90px内存在唯一此类符号、无同样接近的其他站名、无强未拟合符号时才可提出独立候选，不直接换成第二近的圆点。

妈湾厂实际仍被保留为未决：正弦图符虽被检测到，但兴怀文字距该图符47.84px，比妈湾厂57.66px更近，缺少足够的标签／连线归属依据。不能为了补回该站放宽保护。仅凭一例桃源成功也不能覆盖全部异形符号；新样本中的美孚等仍未决。
