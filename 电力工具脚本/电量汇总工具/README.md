# 出清结果汇总上传

工具箱“数据采集 → 出清结果汇总上传”。共用一个复盘文件夹，可执行“仅汇总”“仅上传”或“汇总并上传”。

## 使用

1. 选择“复盘文件夹”。可以直接选混放所有出清 Excel 的大文件夹；默认优先 `~/Desktop/日常工作/复盘`，按 D+1 日期目录匹配，不存在时选最近修改的目录（排除“模板”）。
2. 选择功能；包含汇总时确认输出文件，默认是复盘目录根目录下的 `<文件夹名>_汇总.xlsx`。
3. 包含上传时先点“预览上传文件”，核对原始文件和上传目标。
4. 点击对应开始按钮；包含上传时核对确认对话框。

## 自动归类

点击原有的汇总、上传或预览按钮时，程序先把混放文件移入所选文件夹下的 `东莞、归湖、汕头、海门、海风、鮀莲` 六个单元目录，再执行功能。结构参考 `~/Desktop/日常工作/复盘/模板`，不改动模板，不建“已归类”目录，也不增加新按钮。

- 文件名只识别有效日期和“日前／实时”；单元归属只读取工作表名。谢岗归东莞，华归光伏电站归归湖，广澳海风场归海风，鮀莲光伏电站归鮀莲。
- 支持 `.xlsx`；工作表无法识别或涉及多个单元时，列出文件并停止，不用文件名猜单元。
- 归一类时把文件名统一为 `日前交易结果查询(YYYY-MM-DD).xlsx` 或 `实时交易结果查询(YYYY-MM-DD).xlsx`，去掉机组编号等前缀；同单元同日同类型多份时在日期后加 `(2)`、`(3)`。
- 移动前后校验文件内容，保留日期和格式；同名文件分别保留，不覆盖。移动中断时尽量恢复原位置，未能恢复的路径写入日志。
- 缺少单元时提示具体名称，已有数据继续汇总和上传；再次运行不会重复移动已整理文件。
- `日前节点电价查询(日期).xlsx`、`实时节点电价查询(日期).xlsx` 放在复盘文件夹根目录，保留原名和原位置，作为额外汇总来源，不移入单元上传目录。

## 汇总与上传

- “仅汇总”也支持单个场站文件夹，保留原始日前、实时字段顺序和显示精度，不需要 Node.js。
- 每个来源工作表须包含完整且唯一的 24 个整点；同一时刻重复（包括 `0:00` 与 `00:00`）时停止汇总并提示文件、工作表和时刻，保留已有汇总文件。
- 节点电价在场站工作表后追加“海风汇总”：第 1 行为“海风日前 表内日期”，第 2 行 A:CR 为日前 96 点电价；第 3 行为“海风实时 表内日期”，第 4 行 A:CR 为实时 96 点电价。日期取节点明细工作表标题，日前与实时可不同日；顺序为 00:00、00:15 至 23:45，每个时点对节点名称含“海风”或“升压站”的节点等权平均，同时命中只计一次，不合并小时。数值保留完整计算精度，显示两位小数。
- 仅读取含“节点名称”“数据项”表头的节点明细，数据项须为 `电价(元/MWh)`；全省电价不纳入海风节点平均，无节点名称的辅助表不纳入。完整、唯一的 96 个十五分钟时点及所有入选电价均须有效，空值不会按零处理；节点重复、日期混杂或同类型多份文件时停止，保留已有汇总。
- “全省汇总”位于最后：第 1 行为“全省日前 表内日期”，第 2 行 A:CR 为日前 96 点；第 3 行为“全省实时 表内日期”，第 4 行 A:CR 为实时 96 点。按“全省”工作表及“全省”行标签定位，直接读取原始电价，不计算节点平均；依时段表头排列为 00:00～23:45，显示两位小数。全省电价重复或无效时停止，来源缺失时保留日期标题、对应 96 点留空并提示。
- 仅有节点电价文件也可汇总；缺少日前或实时文件时保留对应标题和空白 96 点，并提示缺失。没有节点电价文件时保持原有场站汇总工作表。输出在替换原汇总前回读核对海风与全省共 384 个电价单元格、数字格式、日期标题和末尾工作表位置。
- 上传需要私有数据上传工具及其 Node 依赖，沿用该工具的独立登录态和文件匹配规则，不自动重试。
- “汇总并上传”先生成 Excel，成功后再上传原始匹配文件；汇总失败则停止。汇总文件应放在复盘目录根目录或目录之外，避免进入上传匹配范围。
- 上传中断时先到目标系统确认结果，再决定是否重跑；包含上传的任务开始后不可安全取消。
