## 实现边界

独立 debug 模式只替换工作进程中的网站采集边界。样例调用现有 `export_online_energy.py` 的日期展开和 Excel 导出函数，不重复实现报表布局。每次使用独立输出子目录，避免覆盖此前结果；工作进程与验收脚本分别重新打开实际文件，核对值、字段顺序与数字格式。

日期字段为原生 HTML 文本输入框，`label` 与固定 `id` 关联，提交读取实际表单值，避免辅助技术修改后只读取陈旧的 React 状态。验证错误使用 `role=alert` 并移动焦点；状态使用 `output`、`role=status` 和实时通知。按钮使用原生禁用状态，日志可用键盘展开并访问。
