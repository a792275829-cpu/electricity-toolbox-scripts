# 市场表更新

工具箱“数据采集 → 市场表更新”。按一个基准运行日抓取市场负荷、日前／实时市场、发电侧与用电侧结算、运行方式等数据，写入指定的年度市场 Excel。会修改所选工作簿，运行前请关闭 Excel/WPS，并自行保留备份。

## 使用

1. 首次使用先在工具箱右侧“清能网站账号”填写并保存账号密码。
2. 填写“基准运行日期”。
3. 选择市场 Excel；默认是桌面“日常工作”目录中的 `现货统调市场出清、结算数据2026.xlsx`。
4. 按需调整“覆盖非空单元格”（界面默认勾选：已有数值也写成本次抓取结果，公式单元格保留、跳过）和“写入前生成时间戳备份”（界面默认不勾选）。
5. 确认工作簿含 `2026年市场情况`、`2026年运行方式及成本` 两个工作表及对应日期行。
6. 关闭正在打开该文件的 Excel/WPS，点击“开始更新”。

## 命令行

```bash
.venv/bin/python 市场表更新/update_market_table.py --date 2026-11-02 --workbook "/path/市场.xlsx"
```

`--headed` 显示浏览器，`--login` 只登录；`--skip-existing` 保留已有非空单元格（命令行默认覆盖），`--no-backup` 不生成时间戳备份（命令行默认生成）。

## 写入口径

字段顺序、工作表、列范围和来源日期由 `toolbox_shared/market_contracts.py` 定义，`tooling/fixtures/market_contract.json` 是固定契约快照。改动前必须确认这几项，不能按报表名称推断。

| 数据 | 来源日期 | 目标工作表和列 |
| --- | --- | --- |
| 市场负荷信息：日前 | D | `2026年市场情况`，`B:U` |
| 日前市场 12 项 | D-1 | `2026年市场情况`，`V:AG` |
| 市场负荷信息：实际 | D-2 | `2026年市场情况`，`AH:BA` |
| 实时市场 4 项 | D-2 | `2026年市场情况`，`BB:BE` |
| 发电侧结算 12 项 | D-6 | `2026年市场情况`，`BF:BQ` |
| 用电侧结算 7 项 | D-6 | `2026年市场情况`，`BR:BX` |
| 单位变动成本对应电价 | D | `2026年运行方式及成本`，`N:X` |
| 在线机组数、预测检修容量 | D | `2026年运行方式及成本`，`AA`、`AE` |
| 燃煤/燃气开机台数 | D | `2026年运行方式及成本`，`AB:AC` |
| 机组运行方式 | 复制 D-1 | `2026年运行方式及成本`，D 行 `B:M` |

某一数据源当天不可用时，日志说明该映射被跳过，其余映射继续处理。

## 写入行为

- 目标日期缺行且区域安全时连续补齐日期行并沿用原格式；遇到历史缺行、重复日期、表尾汇总内容、合并区域或需要新年度模板时停止并提示。
- 有月份汇总的模板跨月时，先要求补齐月份布局，不推断汇总公式。
- 保存采用同目录临时文件原子替换，不生成时间戳备份。

## 登录态与测试

本模块不读取 `config.json`：是否显示浏览器由命令行 `--headed` 决定，工具箱页面按界面设置执行。登录态、锁和 `.browser-profile/` 独立维护。测试随 `tooling/run_tests.py --suite toolbox --pattern 'test_market_table*.py'` 运行。
