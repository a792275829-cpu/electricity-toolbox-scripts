## v0.1.3 更新内容

- 取消启动时自动预加载 WPS，业务页面首次访问时再加载。
- WPS 预览及写入的来源读取、校验移到后台，避免大表或网络等待卡住窗口。
- 日志分批刷新，限制界面日志及任务事件缓存，改善长任务响应。
- Windows 增加无响应线程栈诊断；支持在主界面查看更新进度，避免重复检查更新。
- 合入现货价格更新等已有维护修改，保留账号、登录状态和业务数据。

## 下载安装

请在下方 Assets（附件）中，按电脑系统选择安装包：

| 电脑系统 | 下载文件 | 安装方式 |
| --- | --- | --- |
| Windows 10/11（64 位 x64） | 以 `_x64-setup.exe` 结尾的文件 | 双击运行安装程序 |
| macOS（Apple 芯片，M1/M2/M3/M4 等） | 以 `_aarch64.dmg` 结尾的文件 | 打开后将应用拖入“应用程序”文件夹 |

当前 Mac 安装包不支持 Intel 芯片。

其他附件无需手动下载：`latest.json`、`.app.tar.gz` 和 `.sig` 用于软件内的自动更新；`Source code` 是源代码压缩包。

安装包已内置 Python、Node 与 Chromium。
