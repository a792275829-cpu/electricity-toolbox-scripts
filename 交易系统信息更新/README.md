# 交易系统信息更新

工具箱“数据采集 → 交易系统信息更新”。从“公有数据管理 → 现货运行日报 → 市场负荷信息”抓取数据，接续更新交易系统信息收集工作簿的 `Sheet1`。日期口径固定为日前 D、实际 D-3。

## 使用

1. 确认工作簿路径，默认 `~/Desktop/日常工作/交易系统信息收集20260901.xlsx`。
2. 填写“日前日期范围”，结束日期为 D。开始日期可以留空：工具会取“最早的缺值日期组”或“最后一组的下一天”，并从那里接续；点日期框弹出左右双月历，左侧选开始、右侧选结束。
3. 如手工填写开始日期，必须与工具算出的日期一致；不一致时停止并提示应填日期，以保持日期连续。
4. 按需勾选“写入前生成时间戳备份”（界面默认不勾选；命令行默认生成）。
5. 点击开始，等待抓取、写入和回读结果。

## 写入口径

- 保留当前分类顺序、最大／最小／平均／总电量四项字段及原有单位换算。
- 日前西电行保留原格式，四个数值留空；实际侧写入西电数据。
- 日前 B 类直接取网站对应数值，不扣减实际西电。
- 每类数据依次写入最大、最小、平均和总电量，字段顺序与样式复制最后一组。
- 历史不同分类布局不套用当前映射；最新模板组仍严格校验。

## 接续与保护

- 已有日期组只写缺值，保留已有数值（含零）和公式，不重复追加日期。
- 接续时按行号复用或插入目标行，保留未更新的行和工作表维度，避免表尾预留格式行导致重复行号。
- 新增日期组沿用模板行及合并格式；目标区域有非日期组内容或合并冲突时停止，保留原文件。
- 沿用同目录临时工作簿、备份和提交回滚流程；保存后回读日期、字段顺序、新增数值，以及原有单元格的数值／公式和数字格式。外部程序同时保存时停止提交。

## 命令行

```bash
.venv/bin/python 交易系统信息更新/update_transaction_info.py --end-date 2026-11-02
.venv/bin/python 交易系统信息更新/update_transaction_info.py \
  --workbook "/path/交易系统信息收集.xlsx" --end-date 2026-11-02 --dry-run
```

`--start-date` 只在需要显式确认起始日期时使用（必须等于工具算出的日期）；`--no-backup` 关闭时间戳备份，`--headed` 显示浏览器，`--dry-run` 只抓取校验不写入，`--login` 单独登录。

## 登录态与测试

复用清能统一账号；登录态、锁和 `.browser-profile/` 独立保存在本模块目录。测试随 `tooling/run_tests.py --suite transaction` 运行。

## 已知限制

- 网站当天数据未发布时对应字段无法写入，日志会说明缺失内容，下次运行继续补。
- 模板本身的公式、合并或字段布局错误不在本模块内修复。
