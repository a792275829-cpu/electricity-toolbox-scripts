# 导出上网电量

工具箱“数据采集 → 导出上网电量”。按日期范围抓取各公司、各机组的上网电量，每个日期写一个 Excel 汇总表。

## 使用

1. 首次使用先在工具箱右侧“清能网站账号”填写并保存账号密码。
2. 在页面选择“导出日期”的开始与结束日期，默认都是昨天；起止同一天即只导出当天。
3. 点击“开始导出”，在页面日志确认抓取与保存结果；完成后可用“打开输出目录”。

结束日期早于开始日期时页面直接提示，不会启动任务。

### 日期选择

点击任一日期框弹出左右两张月历，按两步选择：先点任意一张月历里的日期定开始日期，再点任意一张月历里的日期定结束日期，选完结束日期弹层自动收起。从结束日期框打开时直接进入第二步，点一下即收起。

- 两张月历都能点，所以起止日期在同一个月时，在同一个面板里连点两下即可选完；相邻月份补位的浅色日期也能点，跨月边界不用先翻页。
- 弹层顶部标出当前是第几步、已选的开始日期；底部“确定”随时收起弹层，取值以输入框为准。
- 默认“翻月联动”：翻左侧或右侧月份时两张月历一起推进，始终相邻，适合连续几天到几周的范围。
- 取消弹层右下角的“翻月联动”后两张月历各自独立翻页，适合起止日期相隔较远、需要反复核对跨越月份的范围；提示行会显示“两月独立翻页”。
- 联动状态只作用于当前输入框：重新打开弹层保持本次选择，重启工具箱恢复默认联动。
- 开始日期或结束日期改为空格、Esc、回车、点弹层外部都会收起弹层，不会卡住。

## 输出

输出目录默认 `上网电量抓取/输出/`，可用 `config.json` 的 `outputDir` 改变。每个日期单独一个文件 `上网电量汇总_YYYY-MM-DD.xlsx`，工作表“汇总”的版式与单日导出一致；已完成的日期在后续日期失败时保留。同名文件被占用时另存为带时间戳的文件名，不覆盖正在打开的文件。

## 命令行

```bash
# 单日（等价于起止同日）
.venv/bin/python 上网电量抓取/export_online_energy.py 2026-11-02
# 日期范围
.venv/bin/python 上网电量抓取/export_online_energy.py --start-date 2026-11-01 --end-date 2026-11-03
.venv/bin/python 上网电量抓取/export_online_energy.py --login
```

`--start-date` 与 `--end-date` 必须同时提供，不能与位置参数日期混用；`--login` 只打开登录窗口并保存登录态，不导出。

## 配置

业务选项放 `上网电量抓取/config.json`（从 `config.example.json` 复制），可用字段：

| 字段 | 作用 |
| --- | --- |
| `headless` | 命令行是否隐藏浏览器 |
| `requestDelaySeconds` | 接口请求间隔（秒） |
| `outputDir` | 汇总表输出目录，默认 `上网电量抓取/输出/` |

示例文件不含账号，账号统一写在工具箱右侧或 `.toolbox/qingneng/config.json`；只有命令行调试时才在本文件补 `username`、`password`。

## 数据校验

- 日期范围内只登录一次，逐日抓取；每天的校验在写文件前完成，失败时不留下半个工作簿。
- 响应日期、机组身份和重复记录都会校验；异常时停止导出并保留已完成的日期文件。
- 机组列表中存在、但电量接口未返回记录的机组，保留机组顺序与空白列，日志提示日期、机组和24个缺失时段；其他机组正常导出。
- 未填报的时段及整条空电量数组导出为空白并提示缺失时段数，不按 0 参与计算；非空但不足24点的数组仍停止导出，避免时段错位。
- 汇总表按机组分块，清远区域右侧另有 D+2 计划电量列（按当天日期推算）；计划机组或计划日期与实际不符时停止导出。

## 登录态

本工具独立维护 `auth_state.json`、`auth_state.json.lock`、`.browser-profile/` 与 `.qingneng-session/`，不与其它工具共用，可并行运行。
