# 上传集团每日数据

工具箱“上传与写入 → 上传集团每日数据”。上传能销和省内日报数据到集团系统，上传完成后自动新建集团日报。

## 使用

1. 首次使用先在工具箱右侧“清能网站账号”填写并保存账号密码。
2. 打开页面时会自动在 `集团每日上传/` 中匹配 D-2 的最新能销 Excel；需要更换时点“选择文件”。
3. 只需选择一个能销数据 Excel；省内数据使用内置模板自动生成，不扫描同目录历史文件。
4. 确认界面识别出的日期、数据类型，目标省份应为“广东省”。
5. 正常情况下保持“已上传数据也覆盖”未勾选；只有明确要覆盖目标数据时才勾选。
6. 点击“开始上传”并核对确认清单。

上传和新建日报属于外部写入，任务开始后无法从工具箱安全取消，也不要重复点击或用同一日期重复启动。

## 命令行

```bash
.venv/bin/python 集团每日上传/upload_daily_report.py --cli "广东-能销数据-20261115.xlsx"
.venv/bin/python 集团每日上传/upload_daily_report.py --login
```

| 参数 | 作用 |
| --- | --- |
| `--headless` / `--browser` | 无界面运行 / 使用浏览器页面上传 |
| `--force` | 接口模式下即使当天已上传也重新导入 |
| `--skip-report` | 只上传数据，不新建集团日报 |
| `--smoke-report` | 只验证能否进入日报管理页面，不写入 |
| `--cli` | 不打开图形界面 |

## 配置

接口上传默认无界面运行，浏览器页面模式由 `--headless` 决定是否显示浏览器。账号读取工具箱统一账号，缺省时回退到 `上网电量抓取/config.json`。

## 登录态与测试

本模块独立维护 `auth_state.json`、锁和 `.browser-profile/`；登录态可以复用其它工具的账号，但浏览器 profile 不共享。测试随 `tooling/run_tests.py --suite group` 运行。

## 数据与结果核对

界面只选择能销文件，省内数据固定从内置模板生成，日期以能销文件名为准，写入“省内数据”工作表 A2:K2，输出至能销目录的 `广东-省内数据-YYYYMMDD.xlsx`。命令行仍兼容显式传入自定义省内文件。C2 为公式时替换容量项并计算为数值；C2 已是数值时保留原值，允许历史数值模板跨日复用。A2 日期、B2 台数、C2 数值及数字格式回读一致后才提交文件。

接口和浏览器上传前后均查询日报状态。接口返回多个省份时按日期、广东省 provinceId=44 和类型筛选；类型兼容 dataItemName／groupDataType 枚举和 dataType 中文名称。目标记录缺项、重复、类型冲突、状态无效或查询不到时停止，不继续新建日报。空列表表示未上传，提交后必须查到 dataStatus=1。
