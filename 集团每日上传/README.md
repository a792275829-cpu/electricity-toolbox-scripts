# 上传集团每日数据

工具箱“上传与写入 → 上传集团每日数据”。上传能销和省内日报数据到集团系统，上传完成后自动新建集团日报。

## 使用

1. 首次使用先在工具箱右侧“清能网站账号”填写并保存账号密码。
2. 打开页面时会自动在 `集团每日上传/` 中匹配 D-2 的最新能销 Excel；需要更换时点“选择文件”。
3. 可以只选能销数据，也可以同时选省内和能销数据。
4. 确认界面识别出的日期、数据类型，目标省份应为“广东省”。
5. 正常情况下保持“已上传数据也覆盖”未勾选；只有明确要覆盖目标数据时才勾选。
6. 点击“开始上传”并核对确认清单。

上传和新建日报属于外部写入，任务开始后无法从工具箱安全取消，也不要重复点击或用同一日期重复启动。

## 命令行

```bash
.venv/bin/python 集团每日上传/upload_daily_report.py --cli a.xlsx b.xlsx
.venv/bin/python 集团每日上传/upload_daily_report.py --login
```

| 参数 | 作用 |
| --- | --- |
| `--headless` / `--browser` | 无界面运行 / 使用浏览器页面上传 |
| `--force` | 接口模式下即使当天已上传也重新导入 |
| `--skip-report` | 只上传数据，不新建集团日报 |
| `--smoke-report` | 只验证能否进入日报管理页面，不写入 |
| `--cli` | 不打开图形界面 |

## 配置

`集团每日上传/config.json` 只影响命令行：`headless` 决定直接运行脚本时是否显示浏览器。工具箱界面上传始终显示浏览器。账号读统一账号，缺省时回退到 `上网电量抓取/config.json`。

## 登录态与测试

本模块独立维护 `auth_state.json`、锁和 `.browser-profile/`；登录态可以复用其它工具的账号，但浏览器 profile 不共享。测试随 `tooling/run_tests.py --suite group` 运行。
