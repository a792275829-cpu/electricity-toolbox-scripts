# WPS 写入工具

预览、手动登录状态检查、工作表读取和写入可取消。正在写入时，当前目标文档先保存并回读，尚未开始的文档跳过。页面自动检查登录状态，不妨碍关闭或重启工具箱。

把本地 Excel 或 KDocs 的来源区域，写入一个或多个目标 KDocs/WPS 表格区域。工具箱入口在“上传与写入 → WPS写入工具”。

## 使用

1. 新建或选择一个文档配置。
2. 填写目标 KDocs URL。
3. 选择来源类型：本地 Excel 或 KDocs。本地 Excel 需要选择文件，KDocs 需要填写来源 URL。
4. 为每个区域填写来源工作表、来源起止单元格、目标工作表和目标起止单元格。
5. 确认每个区域的来源与目标行列数一致。
6. 保持默认的“WPS 专用浏览器（推荐）”，点击“登录 WPS”。
7. 在弹出的专用 Chrome 中完成 WPS/KDocs 登录，回到页面点“刷新登录状态”确认连接可用。
8. 选择一个或多个文档配置点“Preview”，核对来源、目标和区域尺寸。
9. 点“开始写入”后，在确认窗口核对覆盖提示。确认后，工具会覆盖所选配置目标区域内的单元格，包括已有数据和公式。取消会直接返回页面。写入、保存和回读结果可在页面专用日志查看。
10. 需要复用配置时使用 Import/Export。导出文件包含写入区域和运行选项，省略来源链接、本地文件路径、目标链接和链接历史。导入旧配置文件时也忽略这些字段，并保留本机的链接历史和文档名称缓存。旧配置中的覆盖选项统一按整区域覆盖处理。

原版和 WebView 在各自的数据目录读取本机配置。文件缺失时加载随包默认配置；文件无法读取或格式无效时保留原文件，页面显示空配置列表。

来源和目标链接均以“链接（表格名称）”显示，保存及读取时只使用原始链接。点击来源链接旁的“刷新来源工作表”会切换到“金山文档”并异步读取来源文档名称和全部工作表；选择来源链接或在链接输入框按回车也会读取。编辑已有在线来源配置时自动读取来源和目标工作表。选择本地文件则切换回“本地表格”。

读取完成后，“添加区域／编辑”的来源工作表下拉列表使用最新读取结果；已打开的区域窗口也可展开下拉获取刷新后的工作表。切换来源链接时清除旧链接的工作表候选，过期读取结果不覆盖当前选择；读取失败时提示具体错误并可重试。

写入前会把所有目标工作表和单元格区域一次性定位校验；任意一个区域不存在或无法定位时立即报错，不写入任何单元格，错误信息标明第几个区域及其目标位置。赋值完成后保存一次，再回读每个区域的值与来源核对。

只补空白时按单元格赋值，不重写整个区域，保留已有公式及单元格格式。回读按“本次补入值＋原有保留值”核对；已有公式核对公式本身，允许填入空白后正常重算。来源日期、工作表、区域范围及字段顺序仍按原配置执行。

写入前建议在目标表保留副本；不要同时用多个窗口写同一个目标区域。

WPS 登录状态在原版与 WebView 界面使用相同配色：服务确认“已登录”时为绿色，未登录或登录失效时为橙色，尚未检查或无法确认时为灰色。

## 连接方式

| 方式 | 说明 |
| --- | --- |
| WPS 专用浏览器（推荐） | 工具自动启动并常驻后台，使用独立 profile；点“登录 WPS”扫码一次后长期有效，后续预览和写入都连这个实例。 |
| 连接已打开的浏览器 | 连接你自己用 `--remote-debugging-port=9222` 启动的 Chrome，适合已有独立 profile 或专用浏览器无法启动时使用；需要在“浏览器连接地址”填对端口。 |

配置里只保存这两种取值，无法识别的连接方式会回到默认的“WPS 专用浏览器”。

## 专用 Chrome

macOS 默认通过本机 `127.0.0.1:9222` 连接独立 Chrome 会话，profile 与日常 Chrome 分开：

```text
wps自动/启动WPS专用Chrome.command
```

首次启动后在这个窗口登录 WPS/KDocs，保持窗口运行再回工具箱预览或写入。提示无法连接时，先关闭占用 `9222` 的旧专用窗口，再重新启动。

## 配置文件

| 文件 | 说明 |
| --- | --- |
| `wps自动/wps_excel_to_kdocs_config.json` | 本机配置：账号无关的文档配置、目标链接、区域和界面选项 |
| `wps自动/wps_excel_to_kdocs_config.defaults.json` | 随包默认配置，3 项写入配置、共 39 个写入区域 |
| `wps自动/logs/` | 写入日志 |

首次使用且没有本机配置时自动载入默认配置；已有本机配置（包括自行清空的）优先保留，不会被更新覆盖。桌面安装包首次安装把默认配置初始化到用户目录 `data/wps自动/wps_excel_to_kdocs_config.json`。

默认配置保留来源与目标工作表、单元格范围和字段顺序。使用默认配置或刚导入的配置时，先选择本地文件或填写来源链接，再填写目标表格链接。调整随包业务配置时改 `.defaults.json`，日常界面修改继续留在本机配置里。

## 实现

- `wps自动/config_model.py`：配置字典与 `DocumentConfig`／`MappingRow` 互转。
- `toolbox_shared/wps_values.py`：数值转换与区域逻辑。
- `toolbox_shared/wps_browser.py`：浏览器与 CDP 生命周期（不依赖 Tk）。
- `toolbox_shared/wps_service.py`：Excel 读取、映射、写入与回读。写入前统一预检目标工作表／区域，赋值后一次保存并逐个回读核对值。
- `toolbox_shared/wps_config.py`、`wps_urls.py`、`wps_paths.py`：默认配置合并、URL 解析、路径与启动锁。

独立入口为 `wps自动/wps_excel_to_kdocs_gui.py`（`wps写入工具.pyw` 为双击版本）。登录状态、锁和浏览器 profile 按工具隔离，不进入版本控制。

## 来源缓存与阶段超时

本地来源区域包含公式时必须有计算缓存；缺缓存会在写入目标前停止，提示用表格软件重新计算并保存。数字 0 和明确的空字符串缓存均有效。

在线读取以及目标读取、写入、保存、回读均有阶段超时（各 120 秒）。写入阶段通过读取属性等待 SDK 队列完成。读取失败且尚未赋值时提示未写入；赋值后失败、保存／回读超时或连接中断时提示可能已部分写入，请先核对网站。开始赋值后不因导航错误自动重试。超时无法撤回网站已收到的请求。
